# 韦斯·安德森海报

创作一张有明确主角、整幅布局秩序、可信的人物与物件比例、主体对称与精确编排、复古美术和艺术化主副标题的电影海报。主角可以是一人、几人、一群人、一物或一组物件，也可以是道具阵列、建筑或空间关系。

**共同的视觉基础是经过精确美术设计的电影布景写实：正面或明确的机位、清楚的结构、柔和的照明、真实材料与经过组织的颜色。** 场景有舞台般的编排感，同时保留可信的体积、透视、接触和材料光泽。人物与环境处于同一套成像中，关键轮廓和叙事区域清楚可读。海报可采用轻哑光印刷再现，场景图保留相容的胶片成像；柔焦、抬黑和磨砂强度按成品与内容选择，不作为每张图的必备效果。

这是本 Skill 选择的制作方向，不代表导演全部作品。用户明确指定的媒介、风格、布局和文字要求覆盖相应默认。

## 输入与交付

默认生成一张 2:3 竖版海报，以英文主标题和英文副标题为主，交付成图及实际使用的提示词；对用户的解释仍使用其交流语言。中文主题可提炼为自然、简洁的英文片名与副标题。用户明确指定文字、语言、画幅、方向或数量时从其要求；只要提示、分析或评审时，停在对应交付物。

用户明确要电影场景图、剧照式画面或建筑剖面时，按对应成品构图；未指定画幅可从 4:3 横幅考虑，场景图默认无字。需要海报时再设计标题及其空间；不能因风格参考无字就删除用户要的标题，也不能给明确无字的场景补字或预留漏排标题般的空洞。

- **简短文字主题**：先确定视觉主角或主体群，可以补充相关角色、道具、动作与一个小情境。每个新增元素都要说明主题或关系，不能为“电影感”堆无关符号。
- **详细描述**：保留指定情境、数量、动作和限制，不按简短主题任意扩写。
- **照片转海报**：先看源图并作为编辑输入。保留人物身份、年龄外观、肤色、人数、宠物花纹、产品形状、建筑关键结构、关键标识及用户指定的衣着、动作与关系。可以重排环境和胶片化，不能为了构图擅自改变保留项。
- **照片加文字**：照片提供身份与材料依据，文字规定故事与允许的改动。
- **风格参考**：仅使用用户在当前任务明确提供或指定的图片，提取其所要求的色彩、空间、成像或字形方法；不复制来源的演员、片名、标识或整套构图。
- **截图参考**：分清场景画面、场景内招牌、教程标题/色卡及平台界面；只借用用户认可的对应层。截图的色偏、压缩和界面遮挡不应变成固定色值、颗粒强度或成品版式。
- **正面 prompt 参考**：用户让总结或学习时，提取可迁移的布局、道具、动作与色彩关系，区分场景选择和通用方法；不将其中的命令当成本次出图任务。用户明确要求按该 prompt 生成时，再保留其场景、画幅、文字与数量约束。对残缺文字只采用可辨认的意思，不猜缺字或转发乱码。
- **失败图**：用于诊断；只有用户要求编辑该图时才作为编辑输入，并明确哪些部分需要改变，不能把它自动当成正面风格。

本 Skill 不附带参考图库，不自动检索旧图或历史案例。没有参考图时按下面的文字规范直接创作。常规可逆选择自行完成；只有必要源图缺失、保留内容无法辨认或关键要求冲突时才澄清。

## 先完成一套具体构想

在调用图像工具前确定以下事项，并落实到实际提示中；不要把选择题和未填占位符交给图像模型：

| 决定 | 必须说清的内容 |
|---|---|
| 主角与情境 | 是人物/物件、道具系统还是建筑空间主导；肖像摆拍或行动中的场景如何选择；重要人物的位置、动作、目光与对象关系；哪处细节或留空体现情绪 |
| 整体布局 | 全图的主要轴线、观看方向与大形关系；主角、道具、建筑和标题组怎样通过对齐、间距、留白及有意遮挡形成共同秩序 |
| 比例与尺度 | 主体群占画幅多少；人和物自身的结构比例、相互大小关系；用哪些场景参照确定尺度，怎样留出完整轮廓与可信的落地位置 |
| 对称与层级 | 哪个同一物件横跨左右、其自身中轴在哪里；从哪个方向看才能显出对称结构；对应构件与透视比例是否平衡；哪些独立物件保留高矮大小差异；背景与遮挡关系 |
| 材料与成像 | 哪些结构与叙事区域须清楚；光从哪边来，亮暗如何形成体积；不同材料的纹理与光泽怎样区分；本次采用何种胶片或印刷处理 |
| 颜色分工 | 从本地电影色板或用户配色中选哪一组、为何适合；通过道具阵列、建筑分区或主辅区域怎样组织颜色；具体载体、面积、冷暖与明暗如何形成主次，调色后保留哪些关键区别 |
| 主副标题 | 默认英文的精确文案与大小写；字形骨架、变体/连笔/花饰；整组文字的构图、路径、大小节奏与阅读起点；互相一致的尺寸、字距与留白；字色与底色；副标题的位置与从属关系 |

先建立布局和尺度关系，为图文共同预留空间，再细化光色、材料和字形。画幅占比与对象结构必须同时成立；空间不足时调整取景、位置或文字留白，不压缩人体或拉扯物件来满足占比。比例服务于本次内容，不固定主体大小、人数、背景结构、色卡或标题位置。不要把“协调、复古、有层次、有艺术感”当成已完成的设计决定。

当道具系统、建筑主导、多人物行动、剖面或并置生活构成本次重点时，读取 [场景组织方法](references/scene-composition.md)，选用相容的结构。普通肖像或单物海报无需逐项套用；复杂场景也不应被强行压成“中央人物加背景”。

## 1. 整体布局、主体编排与复古美术

**先建立整幅画面的秩序。** 默认采用清楚的主轴与接近正面的编排，让主体群、主要建筑或承托物、标题组的总体重量围绕它组织。用共同对齐、重复节奏、明确间距和成片留白连接主要形状；有意的偏移应服务情境和视觉平衡，不能让每个元素各占一个中心。整体秩序不要求每个独立物件或字母镜像。

先让本次主角成为能被一眼读到的整体。人物或物件群可通过聚合、间距、共同朝向、交错高度或重复形状形成视觉中心；道具系统或建筑主导时，先让阵列、单元或大面关系清楚，人物的尺度与位置服务于它。多元素时让关键动作、手持物与主要结构有足够辨认空间；交叠应说明关系，避免无意相切、零碎遮挡或道具横穿身体。道具和空位共同参与编排，丰富的陈列也可有秩序，不能只凭题材相关就不断填满空处。

复古意味落实到相容的造型语言：服装剪裁、家具轮廓、墙裙与饰线、灯具、器物材料及陈列节奏。拱门、球形灯、黄铜、格纹或绒面可以因题材选用，不是必备清单。场景可以洁净、完整，年代感不要求大面积磨损、褪色或旧纸纹理；也不自动加入胶卷、老相机、邮票等符号。趣味来自一个可观察的小关系，不靠夸张表演填满画面。

**以人物肖像或摆拍群像为主的海报，默认直视镜头，与观者建立直接目光关系。** 头脸以正面或能自然对视的轻微角度呈现，姿态清楚，神情克制，保留有意摆拍的仪式感和成员差异。行动中的叙事场景则按角色安排动作、目光与对象：服务者关注手中的餐具，阅读者看书，各房间的居民可互不知晓。严肃或平静不等于僵硬合影；不让“正面机位”自动变成“所有人看镜头”。用户指定的视线、动作与照片保留项优先。

温暖或明亮的环境可以容纳专注、等待和疏离的人物。用距离、朝向、停顿与各自的动作形成情绪，不因配色温暖就自动让所有人微笑；用户要求的情绪仍优先。

**同一个物件横跨画面左右时，优先保证它自身的结构尽可能对称。** 先定物件自身中轴，再选择能显出对称面的观看方向；检查两侧外轮廓、对应部件、尺寸与透视比例是否平衡，裁切是否完整。具有左右结构的物件不能随意转成侧视，再用“位置居中”替代结构对称。这是主体构图的重要判断，不只是装饰性选择。

**多个独立物件之间不要求造型镜像。** 它们可以高矮、大小、形状与位置不同，通过间距、排列和视觉重量形成秩序；不能为左右相同而复制整个环境。群像允许动作、表情和身高差异，天然纹理与小细节保持变化。原物确有非对称结构或用户要求保真时，保留其特征，用视角与编排尽量平衡，不伪造结构。

建筑外壳、重复框架与内部单元分开判断：外部轴线和间距有秩序，房间的用途、陈设、颜色和人物活动仍可不同。两侧的视觉重量平衡也能表现彼此分离，不必镜像同一组家具或动作。

## 2. 正面秩序与真实纵深

优先用接近正面的观看方向、稳定的轴线和清楚的遮挡组织场景。主立面可以像舞台一样易读，地面、家具、泳池、走廊与楼梯仍有真实透视和可比较的远近尺度。按本次主体选择浅层陈列或有纵深的空间，不强制将所有场景压平；视角不能破坏照片保留项。

门洞后的走廊、窗口或远景可以连接或分隔主要空间；餐厅与泳池也可让纵深成为构图的一部分，透视应服从同一机位与整体层级。剖面场景保留楼板、外壳边缘与必要街面等线索，多层连通空间交代楼梯和平台的承接，避免把房间画成互不相干的拼贴。并行故事所处的房间与楼层应保持可读。

先分清主体、承托它的环境和后方背景，再决定哪些轮廓交叠。空间层数按内容需要；不用为了凑三层强加左右前景，也不把画面切成等高、互不相干的横条。可通过合成调整完整对象的位置与等比尺寸，并共同核对场景尺度；连接处应具有一致的光色、颗粒与边缘表现。

### 人、物与场景的比例

| 检查层面 | 制作决定与可见结果 |
|---|---|
| 对象自身结构 | 人体保持与年龄、体型及源图相符的头身、肩宽、躯干、四肢和手脚关系；全身构图留出完整身体，服装遮挡下的腰胯、膝盖与脚踝仍在合理位置。物件的长宽厚度、部件大小、轴线和连接关系属于同一套可信结构；不为构图分别压短或拉伸局部 |
| 对象之间尺度 | 将人物、建筑、家具、交通工具与手持物放在同一尺寸关系中，选择画内可见参照共同设计。例如手持物与手掌的相对大小符合其用途，人物与旁边的门或家具大小协调；不对每个对象独立指定互相冲突的画幅占比 |
| 空间一致性 | 相近深度的对象保持可比较尺度，前后缩放符合相同视点；遮挡、支撑、脚底或底座接触位置一致。先分清对象在地面、台阶还是后方，不能靠悬空或改变对象长度补偿位置错误 |

保留自然身高、体型及不同物件的真实差异，不设固定头身比或统一模特比例。用户明确要求微缩、巨物、夸张造型时按该设定建立一致关系；照片保留项优先。选择浅层陈列时，只调整取景与对象排列，不压缩人体长度或物件结构。

### 空间中的材料分工

| 画面部分 | 具体表现 |
|---|---|
| 主体 | 轮廓与身份特征最容易辨认；主要结构清楚，表面有少量自然不规则与轻柔明暗；不必让每处毛孔、纹理或缝线都突出 |
| 后方环境 | 保留真实形状、连续色调和残留材质。只承担陪衬时可轻度柔焦、降低局部反差；承担动作、阵列或建筑叙事的区域须清楚可读，不能因位置靠后就模糊掉，也不能变成无内部变化的填色 |
| 大面积承托环境 | 保留与材料相符的纹理、明暗起伏和反射；地砖、木板或池边的尺度变化可帮助读取纵深，细节密度服从视觉层级 |
| 主体与环境交界 | 用接触阴影、遮挡、必要压痕及与材料相符的反射使主体落在场景中；阴影深浅和边缘随光照决定，不能出现硬剪边、白色描边或悬浮接触 |

正面秩序主要由机位、排列、遮挡与大形关系建立。背景柔焦是降低陪衬信息的可选方式，建筑和多人场景可以保持跨区域的清晰度；不能靠整体模糊或删光纹理代替构图。实际提示写出本次观看方向、纵深关系、需保持可读的区域及可柔化的陪衬，保留摄影空间中的真实材料。

## 3. 柔和照明、清楚形体与材料差异

先让布景、人物和物件在共同光线下成立，再决定胶片与印刷处理。保留电影摄影的清楚轮廓、自然细节和细腻色调；光照过渡柔和，接触、暗部与材质仍有分量。布景感来自精确选择和编排，不要求把材料改成塑料、微缩玩具或无差别的光滑模型。

| 部分 | 要得到的可见效果 |
|---|---|
| 光线与轮廓 | 用宽软主光、漫射日光或相容的室内灯光形成柔和过渡；门框、柜格、栏杆和人物轮廓保持可读。控制过度锐化与刺眼高光，不把柔光做成全画雾化 |
| 明暗与色调 | 高光平缓收住，受光面、背光面与接触暗部有区别；深色可以浓重并保留层次。只有本次追求柔化印刷影调时才轻抬黑位，不把暗部一律洗灰 |
| 材料光泽 | 织物的柔软、木面的纹理与缓和反光、黄铜的小范围亮点、石材和水面的反射各有区别；光泽强弱由具体材料与灯光决定，整体柔和仍保留这些差异 |
| 细节与表面 | 皮肤、缝线、饰条、家具边缘等保留必要摄影信息，清楚程度按画面职责分配；表面可以洁净完整，允许细微自然变化，不用等密度微纹理填满大面 |
| 胶片颗粒 | 需要时使用细微、自然、融入影像的颗粒；正常尺寸先读到场景和材料，不要求颗粒抢眼或必须可见，不用噪点强度证明胶片感 |
| 海报印刷适配 | 可加入轻哑光、细微相纸或印墨再现，并让图与字属于同一成品；处理后仍能辨认场景里的金属亮点和地面反射。纯场景图不自动增加纸面、磨砂或旧印刷效果 |

海报采用纸面或印墨质感时，保持轻微，不自动增加纸张边框、实物纸张投影、厚纤维、折痕、划痕、污渍或重暗角。成品表面的哑光处理与画中物体自身的光泽是两个层面，不能用一层磨砂将两者混为一谈。

若缺少目标质感，先检查布景造型、材料分工、光线与颜色是否相容，再调整成像。泛灰或发糊时恢复必要暗部和结构边缘；所有材料同样发亮或同样发闷时重写各自表面；颗粒形成粗砂或噪点膜时降低它。不要反复堆叠滤镜，主体身份和文字可读性始终保留。

## 4. 先选电影色系，再分配颜色与调色

**选择命名色板或需要默认配色时，先读取 [电影色板参考](references/wes-palettes.md)。** 它收录 `karthik/wesanderson` 的离散色值，是社区整理的电影配色参考，不是导演官方调色规范，也不是整幅照片的调色表（LUT）。选色建议与画面分配是本 Skill 的海报设计适配。

按主题情绪、场景材料和需要保留的颜色选一组相容的色系。用户指定色板、色值或照片保留色时优先采用；已给足颜色信息时无需为了匹配名称强行替换。没有指定时从参考中选择，不能每次自动落到同一组奶油、赭色与青绿。冷蓝、粉紫、灰绿或浓暖色都可在统一的胶片再现中成立。

色板是选色锚点，顺序不等于主次或面积。先选本图有用的颜色，再落实到画面；不必用完，不混用整套目录，不照抄电影布景。需要补充浅底、阴影或文字墨色时，从已有色相与明度关系推导，明确它是调整或新增色，不冒称上游原值。

颜色也可通过结构呈现：道具阵列按颜色与形状排列，房间各有主色，相同拱间形成颜色序列，或大墙面与楼梯构成分区。选择本图适合的方式，让单元共享必要的饰条、材料或光线；整体统一允许局部颜色身份不同。具体做法按 [场景组织方法](references/scene-composition.md) 的相应部分执行，不把所有颜色平均填进所有区域。

| 颜色角色 | 选择与分配 |
|---|---|
| 主色与辅色 | 让背景、建筑、服装或主体等有可观面积的区域分别承载，明确谁占大面、谁形成对照；面积由本次布局决定，不固定比例，也不能全靠小道具体现色板 |
| 浅色与受光 | 选与色系相容的浅底或受光色，可以是米白、浅粉、淡紫、灰蓝等；有光照与材料变化，不将所有高光染成同一种黄白 |
| 深色支点 | 由已有深色或同系派生墨色稳定主体轮廓与文字；同时检查字在实际底色上的反差，缺少深色时可以补充 |
| 点缀与浓色 | 用位置、邻接与面积控制鲜明程度；色板中的纯红、亮黄或青绿可以保留作用，不必一律洗灰，也不让每个区域同样抢眼 |

浓色也可以承担大面：酒红地面、芥末黄墙面或深青绿布景都可成为主色。先限制互相竞争的颜色种类，安排区域、明暗和相邻关系，再决定是否降低某个局部彩度；饱满与协调可以同时成立，不把“受控”自动解释为低饱和。

对每个关键色，写“颜色名称＋需要时的 HEX → 具体载体 → 面积与位置关系”。颜色名称帮助模型理解材料与情绪，HEX 帮助定位；它们不要求皮肤、织物或阴影每个像素严格等于色卡。保留摄影材料自身的过渡和邻近色，不把图像量化成色块图。实际提示只包含已选颜色及用途，不要求画出色卡或色号。

**先保持选定色相、明暗与冷暖关系，再用相容的胶片调色统一。** 暖色方案可有奶油般高光；冷色、粉紫方案保留自身浅色。收住刺眼高光和多余杂色，保留饱满主色、必要深暗及肤色、产品色。统一来自共同光线、布景配色和成像响应；抬黑、降彩或哑光只用于本次需要的处理，不能把所有色系统一成黄棕或灰粉。

提示可写 coherent cinematic color、soft highlight roll-off、substantial colored shadows、rich controlled color fields、preserved hue separation，并落实到具体颜色与区域。仅在选定印刷效果时加入对应处理；不默认 maximum saturation，也不把有辨识度的浓色一概禁止。

遮住文字后，大色域仍应体现所选组合和主次；看回全图，字色也属于同一体系。颜色碰撞时先检查面积、邻接和明暗，再调整彩度与调色；若一团灰棕，先恢复被罩色吞掉的色相，不能只提高整图饱和度。

## 5. 主标题与副标题共同成形

海报默认英文两级文案，明确无字的场景跳过本节。未提供最终文案时，主标题用自然、精练的英文凝结主题，副标题补充一个情境、情绪或视角，不重复解释主标题，不逐字硬译中文。用户已指定的标题、句子、大小写与标点逐字保留；明确要求英译时才翻译指定原文。中文、双语、无字、单标题或全文保留要求覆盖默认；不自动为英文再加一层中文。不得编造演员、导演、奖项、上映日期或真实背书。

**把字形设计与文字构图分别决定，再合成一件标题图形。** 字形决定笔画、连笔、回环和变体；文字构图决定整组沿什么路径展开、怎样错落、环绕或穿插。两者都可以承担艺术性，不把完成标准限于换一款字体后居中排成一行。先根据本次题材的情绪、主体轮廓和空白选择一种主导动势，再配合字形；平直排字保留为一种可选方法。

从题材的情绪或视觉关系提炼字体性格：圆润、流动、轻细、饱满、紧密或舒展。下面是骨架方向，不能代替后续构图，也不是封闭模板：

| 方向 | 字体骨架与笔画性格 | 适合的字组处理 |
|---|---|---|
| 圆润复古衬线 | 饱满弧形、柔软衬线与圆滑转折；宽松字腔，中等笔画对比；温暖而有印刷分量 | 紧密但不挤压的词组，柔和起伏的外轮廓；按语义选大小写，不靠膨胀笔画堆重量 |
| 饱满复古连笔 | 有粗细节奏的招牌式 script；圆转的入笔、连贯连接和清楚字腔 | 通常采用首字母大写加小写，词内有意连接、词间留间隔；基线与字母朝向随选定路径或手写节奏变化 |
| 纤细抒情连笔 | 较细、略舒展的书写线条，柔软回环与受控长笔画；保留自然笔压或稳定单线节奏 | 空间更松、墨量更轻；选择一两处首尾或字母连接呼应，长笔画绕开副标题与主体 |
| 圆润几何 | 圆形或椭圆字腔、柔和端点、接近等粗的笔画；比例成熟且重复结构一致 | 清楚的词间距与光学校正字距，适度舒展；适合克制、俏皮的标题，不强制连笔 |
| 刊物与秩序 | 方整或适度窄身的展示字、清楚转折和规律内白，衬线与无衬线均可 | 按语义紧凑分行，保持明确对齐与整组轮廓；作为其他题材的选择，不把所有标题导向刚硬大写 |

字体名只能辅助说明，提示里仍需写出字面宽窄、笔画粗细关系、转折/笔端与内白。圆润、等粗或连笔本身都可以成立，判断在于比例、字腔、连接、节奏和整组轮廓；不能把圆头一概排除，也不能只写“rounded / cursive”就认为设计完成。需要中文时再按偏旁结构设计，不套拉丁连笔，也不默认退回常规宋体。

### 英文字母与连笔关系

先确定本次文案的大小写。圆润衬线与几何字可按语气选择全大写或大小写混排；连笔优先考虑首字母大写配小写，使字内连接自然，用户指定的大小写仍须保留。根据实际出现的字母说明圆弧、字腔、升降部和端点，选少量相邻字母做连接或嵌合。

连笔应沿真实的入笔与出笔方向衔接，连接处保持纤细或有合理粗细过渡；字腔和词间距不能被封住。不要为“连起来”让所有字母粘在一条粗带上，也不对连笔字体机械增加 tracking 把词拆散。允许首尾笔画变成长线、回环、螺旋、花饰或与邻字穿插；装饰从字形自然生长，或作为有意设计的线条与字组共同构图，不能用孤立装饰代替字形设计。

### 表现性文字构图

目标是 expressive typography / typographic composition：文字自身形成有情绪的图形。下面的技法可以单独使用或少量组合，按内容继续创造，不要求每张海报必有某一种：

| 方法 | 怎样构成 |
|---|---|
| 花饰回环 / swash lettering | 从首字母、末笔或升降部延出卷曲、螺旋、长线与回环，呼应主体轮廓或形成外框；笔画粗细和连接属于同一套字形 |
| 弧拱、波浪 / type on a path | 整词沿拱形、下弧、S 形或波浪展开；字母可以随曲线转向，局部宽高也可重画，以保持字腔与节奏 |
| 圆环、环绕 / circular typography | 文字绕圆、椭圆或主体外轮廓展开，可留缺口、把副标题嵌在内侧；说明阅读起点和方向，不必填满整圈 |
| 螺旋、旋涡 / spiral typography | 字组沿旋入或旋出的路径推进，用适当字级变化与疏密控制动势；内圈保持足够间隔，片名仍能连续辨认 |
| 自由组字 / expressive composition | 单词或字母按意义改变大小、位置、角度和基线，通过错落、嵌合、交叠、放射或阶梯形成整体；保持明确的阅读顺序 |
| 线性与形体变形 | 可用单线字、轮廓字、笔画延展、线条穿插，或把整个字组弯曲、鼓起、收腰；形体变化服务于一个可辨的轮廓，而不是机械拉扯 |

标题可以沿建筑轮廓、人物上方、物件之间或空白边缘生长；副标题可以安静排成短线，也可以进入内环、另一条曲线或相邻空隙。主体的结构对称不意味着每个字必须镜像或沿同一水平线排列；用字组的总体重量、呼应和留白与主体平衡。

在实际提示里说清：选什么路径或图形，起止在哪里，文字向哪边读，哪些字变大或旋转，哪一笔形成回环，副标题放在哪里。允许明显、有意的变形和非直线排列；优先保留主题、拼写、词序、字腔与关键主体可见性，不把“整齐”当作唯一验收标准。

### 大小与视觉重量

先看文字实际占据的面积和笔画墨量，再决定字号。细线标题可以更宽、更舒展；饱满圆润字标应相应控制尺寸。英文按整个词组看宽度与字身高度，连笔的花饰、升降部额外留空间，不能让长尾笔把正文挤得过小。短标题不能因字少就放大到占满上半幅，也不能靠缩小所有字获得精致感。需要低矮字标时重新组织比例，不机械压扁字图。

标题组的位置、尺度和阅读路径要与主体轮廓呼应。直线文字可先定行宽或字身高度；圆环、螺旋与自由组字先定整体占据的区域、路径和大小节奏，再安排文字。尺寸要求需能共存，不能把总宽、字高和字面比例独立硬塞给模型。英文可按完整词分组，也可为字母构图有意展开一个词，但须保持清楚的连续阅读关系。最终提示给出本次明确选择，不能只写“大标题”或“适中大小”。

副标题独立选择安静的字体骨架，不直接缩小主标题的装饰字。可从主标题实际字身高度的约 1/6–1/4 试排，按文案长度、可读性和全图墨量调整；这不是固定倍率。圆润或连笔主标题可搭配细衬线、朴素无衬线或节制的小型大写副标题，形成清楚分工。只对适合的非连笔副标题适度放松字距，不用低透明度掩盖粗字，也不硬凑主标题等宽。缩略看先读到主标题，正常尺寸下副标题仍完整清楚。

### 字距、分行与字形定制

按字形、曲率与阅读路径校正视觉间隙，不机械等距：密处留呼吸，空腔大的地方适当靠拢；连笔与有意交叠保留，其余笔画不意外粘连。直线方案可沿中轴或边线对齐，曲线与自由方案以选定动势组织；不强制所有字使用同一基线、角度或字号。标题各部分要有可读的归属关系。

在成熟骨架上定制笔画与字间关系，例如长笔画的收放、局部宽窄、字间嵌合、末端回环。把“定制”写成绘制动作：哪一笔向哪里延展、哪个转折改变形状、哪处内白打开、相邻字怎样衔接，并说明它服务的整体图形。变化可以克制，也可以成为醒目的表现重点；强度由本次概念决定，不一律限制为微调。

区分有意的艺术编排与失控错误：路径带来的旋转、大小错落和装饰线可以成立；无阅读关系的散乱、拼写改变和堵塞关键字腔需要修正。英文拼写、标点与词序保持，中文同样保留偏旁与文字顺序。

### 字色与所在底色

字色从已经统一的整幅色彩关系中选择，兼顾色相呼应与明度区别，不默认深棕或纯黑。可以选择墨蓝绿字配奶油底、深酒红字配灰粉底、暖米黄字配灰青蓝底等关系；按本次颜色决定，不机械沿用组合，也不让文字跳出本次色板与胶片调色。

先在本次背景底色上试字，同时看主体与环境的大色域。优先从其中一个已有色相发展文字墨色，再调整深浅、冷暖和彩度；不要只因“深色字配浅底容易读”就引入画面里没有呼应的冷黑。柔暖低反差画面中的字色可以带褐、灰、红或橄榄底调，保持足够辨识度即可，不必压到近黑。选择犹豫时给少量包含底色、景物色和实际文字的完整配色比较，不能只展示脱离背景的孤立色块。

主标题通常采用一个主文字色。副标题可以同色减轻字重，或使用一个从属色；不是每层文字另配一种高饱和颜色。细字需要更安静的背景与足够对比，不能靠发光、厚描边或阴影补救。若文字在杂乱区域难读，先移动字组或调整局部明度与细节。

默认平面印墨，边缘精细。特定招牌气质可用清楚的单线轮廓字，但不能变成挤出、浮雕、厚边或投影。主副标题的颜色与边缘处理要属于同一张海报；无字版重新平衡图像，不保留漏排文字般的空洞。

## 6. 写成真正交给工具的提示

把已经选定的方案写成一份紧凑、无矛盾的制作说明。主体、背景和颜色必须填入本次具体可见的内容；不要把内部的“主体层、支撑层”等抽象称呼当作画面元素，也不要原样塞入整篇 Skill。

可按以下顺序组织，自然语言即可，不要求固定段数：

```text
Create one [aspect ratio] Wes Anderson-style [chosen poster or cinematic scene], with the photographic realism of a meticulously art-directed film set. Use coherent cinematic color, clear structural edges and soft lighting transitions. Let [the specific arrangement and camera view] organize the scene while preserving believable volume, perspective and material responses. [If selected for this output: add the specified subtle film grain or light matte print treatment.] [For a poster with text: unify the imagery and lettering in the chosen finish.]

The visual lead is [specific subject, prop system or architectural setting and small situation]. Place [each important character, if present] at [position], with [a readable pose or action, gaze target and relationship to actual objects or other characters]. Keep expressions composed and restrained. Compose the entire frame around [chosen primary axis and viewing direction], coordinating [actual major shapes and any title group] through [specific alignments, spacing and clear negative spaces]. Arrange [actual elements] at [positions and mutually compatible visual proportions], with [intentional overlaps that keep key silhouettes and actions readable]. Establish [the relevant repeating framework, what stays consistent, what varies and which spaces remain empty]. For [the single object or structural frame spanning left and right], show its own symmetry from [viewing direction], with [matching contours/components and perspective proportions] balanced around [its axis]. Preserve [height, size, shape or activity differences among independent objects, people or spatial units]. Organize [actual foreground and background forms] through [specific overlap and the chosen depth relationships, with any corridor, floor or opening described]. [When text is requested: reserve the chosen title area without distorting the subjects or architecture.]

Keep [relevant human anatomy and object components] internally coherent, with proportions appropriate to [age, body type, source identity or object design]. Establish [specific relative sizes using visible scene references] within one consistent camera perspective. Place [feet, wheels, bases or supports] on [their actual ground or support planes] with credible contact and occlusion. Fit the layout by adjusting framing and spacing, preserving body lengths and object structure.

Render [specific materials] with [their individually chosen textures, gloss and reflections], preserving [the actual contact and volume cues]. Keep [story-bearing forms, rooms, props or actions] legible across [their actual areas]; use selective softness only where it supports the chosen focus. Use [soft light source and direction], smooth highlight roll-off and substantial colored shadows that distinguish lit planes, recesses and contact. Preserve [the specific metal glints, fabric response or floor/water reflections relevant to this scene]. Keep period surfaces [the selected clean condition or localized natural wear]. [If a matte poster finish is selected: integrate a light print treatment across the imagery and ink while retaining the depicted materials' different surface responses.] Maintain natural photographic detail without artificial sharpening halos or a visible noise veil.

Base the color design on [selected palette name or user-specified color scheme]. Assign [chosen color names and useful HEX anchors] to [specific substantial regions/materials], with [dominant and supporting areas, positions and adjacency], [chosen light or illuminated tone] and [existing or derived deep ink tone]. Keep [the chosen main and supporting color fields] at [their intended chroma], coherent through their placement, relative areas and value relationships. Use a cinematic grade with soft highlights and retained shadow depth, preserving [the specific hue and warm/cool distinctions that define this scheme]. Keep natural material shading, neighboring colors and identity colors within the scene. The color names and codes guide the image; render no palette strip, swatches or color-code labels.

Main title, exactly: "[text in the chosen language and case]". Design it as expressive typographic artwork using [chosen rounded, script or other letter construction] and [chosen composition: swashed wordmark, arch, wave, circle, spiral, free grouping or another specific concept]. Build [letter proportions, stroke rhythm, terminals and counters], and draw [specific connections, loops, alternate letterforms or extensions]. Arrange the lettering along [actual path or spatial arrangement] from [reading entry] toward [direction/ending], with [deliberate size, angle and baseline changes]. Give the complete composition [occupied area, visual weight and relation to the subject] in [specific ink hue against its actual background hue]. Subtitle, exactly: "[text]", with [quiet supporting type and relative size], placed [under, inside, around or beside the title as specifically chosen]. Keep spelling, reading sequence and essential letter structure clear; the lettering may be visibly expressive rather than set on one straight baseline.
```

按需补入照片保留项、用户指定图片的作用、允许的改动与少量针对本次风险的约束。先选成品和布局，填好后删除全部条件说明；不把本模板的选项交给模型。海报文案默认英文，用户指定的文字与语言覆盖默认；不是连笔时删除连接说明，无字时删除文字和标题留白段，单标题时删除副标题段。没有人物、重复结构或跨左右的单体物件时删除相应字段，不为填骨架添加对象。肖像摆拍明确写对视；行动场景写清与动作相符的目光。建筑或道具系统主导时，将它们写为视觉主体并保留必要区域的清晰度。比例段只写当前对象与可见参照；明确的夸张或微缩设定应替换对应真实尺度默认。每条新增描述应改变一个可观察结果，不重复“真实、胶片、复古”凑篇幅。

## 7. 工具与结果检查

使用当前宿主真实可用的生成或编辑工具，名称和参数以实际说明为准。Codex 有内置 image_gen 时优先使用并遵守 imagegen 操作规则；不要假设其他宿主存在同名参数，不擅自换模型、引入新凭据或修改配置。

实际提供图片输入，明确每张的作用；没传入不能声称模型看到了。若工具支持 referenced_image_paths 且目标均有路径，使用路径；只有需要会话图片且工具支持时才使用 num_last_images_to_include，并选能包含全部目标的最小数量，两者不同时提供。没有输入图就不附旧图。按真实参数设置画幅并核对返回尺寸，不把提示中的分辨率文字当成文件尺寸。

1. **整体布局与叙事**：缩略看主轴、大形与视觉重量是否清楚，所选人物、道具系统或建筑是否真正主导；对齐、间距、留空和有意遮挡形成共同秩序。肖像摆拍的对视是否保留，行动场景中的目光与动作、手持物是否相符；人物不应被默认改成合影。跨左右的物件或结构框架在自身中轴、轮廓与透视上平衡；独立物件和单元内容仍有差异。剖面边界、楼层连接与关键活动可读，留空或局部异常发挥本次指定的作用；不能只检查元素齐全或一律要求环境退后。
