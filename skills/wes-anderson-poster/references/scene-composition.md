# 让场景本身形成秩序与叙事

当道具系统、建筑空间、多个行动中的人物、剖面或并置生活成为构想重点时读取。以下为对正面场景提示的创作归纳，不是导演全部作品的规律；应用后仍需看实际成图。用当前题材选择相容的关系，不照搬旅馆、红伞或固定房间数量。

## 先定重复的结构，再定其中的变化

| 组织方法 | 可见构造 | 哪些变化值得保留 |
|---|---|---|
| 道具阵列 | 用格柜、货架、行列或陈列面形成清楚容器，再按尺寸、形状、色相或用途组织物件 | 行李、书、工具等可以形状不同、尺寸不等、局部有图案；对齐与间距把差异收进秩序，不把每件做成复制品 |
| 并排单元 | 相同的拱间、门洞、包厢或工作位共享宽度、结构与分隔物，让一个主色落在每个单元的大面 | 单元的陈设、人物和空位可以不同；重复的灯或饰条连接整体，少量人物与留空让颜色和节奏更清楚 |
| 两个相邻空间 | 让两侧在尺度与视觉重量上对应，以配色、家具和人物动作形成不同身份；门洞、过道或共同地面连接它们 | 结构平衡可以容纳情绪分离；人物不用相互对视，也不必做同样动作。中央开口可形成有真实透视的走廊或远景，与两侧空间共享机位和构图轴线 |
| 剖面与多层空间 | 选定正面视点和房间/楼层关系，交代被移开的墙面、楼板厚度、立面边缘、门与栏杆；连接型空间还要说明楼梯与平台如何相接 | 不同房间可各有主色与活动；保留建筑外壳或街面等线索，使它读成同一座建筑，而不是贴在一起的独立图片 |
| 大面分区 | 用墙、楼梯、窗洞、平台或大件家具承担成片颜色，以共同饰条、地面或光线建立联系 | 区域不必等大；一处小人物或局部浓色可成为焦点。人物大小取决于建筑尺度与叙事，不为了显眼将人放大到破坏空间 |

固定正面视点是这些方法的有效起点，镜头方向、建筑轴线与陈列线应互相一致；不将“对称”写成所有对象都相同。建筑外壳和重复框架可以对称，内部用途、道具和活动仍有差异。具体的行列数或单元数只在本次设计确有需要或用户明确指定时确定；六间房、五个拱间不是固定模板。

道具承担实际功能时才加入：帮助辨认场所、组织色彩、承载动作、建立年代或制造一个清楚的小偏差。先选轮廓与材料相容的一组，再确定哪些重复、哪些变化、哪里留空。内容丰富可以有秩序；“避免杂乱”不等于每次删到空房间。先减少竞争的排列方向、无归属的小物和均匀铺满的装饰。

## 用动作和目光安排人物

为每个需要被读懂的人物确定：**在哪个位置 → 正在做什么 → 手接触或服务哪个对象 → 看向哪里 → 与谁或哪个空间发生关系**。安排的是一个瞬间；不要让同一人同时承担无法共存的动作。

多人场景可用服务、等待、阅读、交谈、观察或经过形成行动关系。中心人物可以锚定轴线，其他人物通过距离、方向和小动作呼应；不要求所有人朝镜头站好。低调的神情与可信动作能够同时成立，“面无表情”不等于手脚僵硬。

并行生活不必让每条故事交汇。剖面中的人可以互不知晓，左右空间中的人可以各自沉浸；通过隔墙、朝向、距离和不同活动表现分离。建筑主导时人物保持相对小，但关键动作与接触仍要能读清；场景需要无人或少人时，不为填满格子补演员。

人物姿态、手持物与建筑比例要一起设计。餐具应落在手或桌上，搬运有握持与重量，楼梯上的脚落在相应台阶，栏杆与人物的遮挡前后一致。只说明本图涉及的关系，不机械列出所有动作检查。

## 让颜色成为空间的一部分

选色板之后，决定它通过哪一种结构呈现：道具阵列中的重复色、房间各自的主色、相同建筑单元中的颜色序列，或大墙面与楼梯之间的分区。用实体承载颜色，保留材料、体积与接触；像色谱一样有秩序，不等于在画上添加一条色卡。

单元可以拥有自己的主色，同时共享少量中性色、材料色、分隔构件或相容光线。彩度与明度按视觉层级分配；全局协调不必让每个房间同色，也不必把每组颜色洗成灰棕。小面积浓色可成为焦点，大面积色块承担整体结构。

颜色也可以表现关系：两人处于不同色域并各做各的事，情绪距离来自分隔、目光与活动共同作用。不要把某个色相固定解释为某一种情绪。相关颜色、面积和载体必须进入实际提示。

## 留空与克制的异常

秩序建立后，判断空位、等待或一个形式过于郑重的物件是否能给主题增加趣味。安静建筑中的一处错位陈设、重复单元里的少量占用、远处背向观者的小人物，都可成为观看的停顿点。

异常不一定需要解释剧情，但要有明确位置、比例和可见作用；物件仍与场景有可信接触、投影或反射。可以没有异常，也不规定每图只准一个。趣味来自整体秩序与局部关系，不靠增加更多奇怪物件或夸张表演。

## 写进提示，并对照看图

只写本次选定的方法：主角是人物、道具系统还是建筑；固定的观看方向；重复框架与允许变化的单元；每个重要人物的动作与目光；颜色如何落在实体上；哪些区域保持可读，哪里留空或承担焦点。不要转发整张方法表。

看图时先问：缩小后能否读出结构与颜色分区，正常尺寸能否读出动作和空间连接。重复结构是否有秩序而内容仍有变化；剖面是否属于同一建筑；人物是否被拍成无关的合影；空位是否保留；局部幽默是否清楚而没有挤散整体。不要只以人物数、道具数或“画面很对称”判定完成。
