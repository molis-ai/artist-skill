# 让场景本身组织叙事

建筑、道具系统、多人行动或剖面主导时使用。先选与题材相容的一种空间关系，再安排其中的差异；这里是创作方法，不是每张图必须填写的清单。

| 场面方法 | 具体设计 | 保留的变化 |
|---|---|---|
| 阵列与陈列面 | 用格柜、货架、行列或承托面形成容器；轮廓、尺寸、颜色按可见节奏排列 | 物件有用途、材质和大小差别；重复不等于复制同一件东西 |
| 并排单元 | 门洞、包厢或工作位共享宽度、结构或间距；各单元用大面积主色确立身份 | 陈设、动作和占用情况不同，空位参与节奏 |
| 两个相邻空间 | 用共同地面、门洞或过道连接两侧，视觉重量相应；中央开口可形成真实纵深 | 保留两侧不同用途和配色，人物可以各自专注、彼此分离 |
| 剖面与多层空间 | 明确正面视点、外壳边缘、楼板厚度与楼层关系；楼梯接到真实平台 | 不同房间各有生活，不画成互不相干的拼贴 |
| 大面分区 | 墙、台阶、地面、窗洞或大件物品承担整片颜色，以共同材料或光线连接 | 分区不必等大；小人物或局部浓色可以形成重心 |

整体秩序由机位、主要框架、间距和颜色的邻接共同形成。道具用于说明场所、活动、尺度、年代或某处微妙偏差；陈列可以丰富，关键是每件东西有归属。自然场景也可通过地形、景物间距和观看方向建立形式，不强制添加建筑或规则阵列。

## 在秩序中安排动作和留空

对重要角色说清：位置 → 一个可见动作 → 手或身体接触什么 → 目光落在哪里。服务、阅读、搬运、等待等活动各自成立；不要让同一人同时做不相容的事，也不把多人叙事拍成合影。

人物按建筑尺度出现，关键动作仍需读懂；人与物之间的接触、栏杆遮挡及脚下支撑保持一致。房间和单元不必全部有人，故事也不必相互汇合。

有意保留空位、距离或一个过于郑重的位置，可以形成停顿或幽默。异常应与题材和真实场面有关，不为了“奇怪”加一个悬空道具；没有异常也可以成立。

## 进入提示与成图

只写本次选定的结构：谁是主角，机位与主要框架是什么，哪些间距或部件重复，哪些内容不同，颜色由什么实体承担，动作与空位在哪里。不要把全部方法转发给图像模型。

缩小看主要形状与色域，正常尺寸看空间连接、比例、动作和留空。建筑的结构对称与单元内部差异同时成立；真实纵深不吞掉主要安排。单纯数人物、数房间或看到镜像，不能代替风格与叙事判断。
