# 韦斯电影色板：选择与画面分配

在需要默认配色或选择命名电影色板时读取本文件，再回到 SKILL.md 的配色与提示流程。无需安装 R 或下载电影图像。

## 色值范围

它是社区整理的电影配色参考，不是导演官方色彩标准，也不是整体调色表（LUT）。

本文件保留 22 组独立离散色板，色值与源文件一致，仅统一 HEX 字母大小写。`Rushmore` 是与 `Rushmore1` 完全相同的上游别名，此处统一列为 `Rushmore1`。源文件另有供连续插值使用的 `Zissou1Continuous`，不作为另一组离散海报色板收录；它的色值也不等同于 `Zissou1`。

列表顺序仅保留上游排列，不表示背景色、主次、面积或必须使用的顺序。连续插值是数据图表的色阶用途，不能直接解释成绘画的颜料混合或摄影调色方法。

## 按内容选色

下面是基于这些色值的海报设计建议，不是电影剧情、导演意图或原画面面积比例的复述。用户指定色板及需要保留的源图颜色优先；名称只帮助选色，不要求复制电影布景。

| 本次想建立的颜色关系 | 可先比较的色板 | 分配思路 |
|---|---|---|
| 青蓝与黄、红形成清爽对照 | `Zissou1`、`Darjeeling1` | 青蓝可占环境大面，暖色进入服装、承托物或集中点缀；按内容调换主次，不把每种浓色等面积铺开 |
| 粉紫、淡蓝与柔暖色并存 | `GrandBudapest2`、`Moonrise3` | 粉紫或淡蓝承载建筑与大背景，暖色参与人物或材料；保护冷色区别，缺少深墨色时可从已有色相派生 |
| 灰绿、赭橙与沉着暗色 | `Moonrise2`、`Cavalcanti1`、`Chevalier1` | 主辅色进入环境与主体的大形，较深颜色集中稳定轮廓与文字；浅色是否补充由可读性决定 |
| 柔浅底与赤陶、暖橙对照 | `Royal1`、`GrandBudapest1`、`FantasticFox1` | 用浅底或较安静的大色域承托浓暖色，保留灰蓝、青色等已有对照；不将所有颜色统一成棕色 |
| 柔和中性色与暗部层次 | `IsleofDogs2`、`IsleofDogs1` | 土色或灰色组织大面，深色控制面积，保留同系明暗过渡和材料差别；需要时利用已有紫、金色形成变化 |
| 青绿与干暖土色的明显邻接 | `AsteroidCity1`、`AsteroidCity2`、`FrenchDispatch` | 让青绿与暖土色或红色由不同大区域承载，按明度和面积控制冲撞；用共同影调与印刷再现统一 |

没有一组完全适合时，围绕用户颜色或本次主题自拟配色，并如实标明；不拼接所有色板。不必使用整组，也不固定颜色面积。材质的受光、暗部和邻近色可以超出色卡；少量新增或派生颜色应说明来源，不伪装为上游原值。

例如粉紫旅馆可选 `GrandBudapest2`：灰粉 `#E6A0C4` 为主要立面，淡蓝紫 `#C6CDF7` 为天空或浅背景，蓝色 `#7294D4` 为门窗，暖粉褐 `#D8A499` 为服装或石材；文字可派生更深的紫蓝墨色。这里的载体与主次、派生墨色均为设计建议，不属于源色板数据。
