# 莫奈：用光与色组织眼前的景物

将同一时刻的空气、光和色彩变化画在一起。景物通过相邻、交叠的笔触逐渐显现；近看能辨认绘画动作，退远仍能读出水面、树木、建筑或人物及它们之间的关系。

**默认采用莫奈 1870—1900 年前后风景与光色研究中的做法，保留景物可读性、活跃色彩和有取舍的笔触。** 需要晚期睡莲时，采用下文无地平线、反射与植被交融的方向。时期、媒介和成品要求以用户为准；不是每张都粉彩、晴天、花园或睡莲。

## 输入与成品

默认从主题生成一张无字油画，画幅随场景选择；横向风景可从 3:2 起步。交付成图和实际提示。只要求分析、提示词或评审时，停在对应产物。

- **简短主题**：补足一个可观察的情境与光照时刻，选择承载它的景物关系。情绪通过光色、距离和节奏体现。
- **详细描述**：保留指定主体、数量、动作与构图限制；不要为加入睡莲或拱桥改掉主题。
- **照片转绘画**：先查看源图并作为实际图像输入。保留人物身份线索、姿态、产品结构和建筑识别点；可用色群概括细节，但不能以松散笔触掩盖换脸、物体缺失或结构变化。要求高度保真时，在关键部位保留足够辨认信息，周围仍使用统一的绘画语言。
- **风格参考**：提取光色关系、笔触尺度和边缘处理，不自动复制原作布局、题目或签名。失败图用于诊断，用户要求修改它时才作为编辑目标。

正文自包含，不要求下载参考图库或调用历史图片。源图、风格参考与编辑目标各自的作用必须在提示中说清，并按当前图像工具实际支持的方式传入。

## 先决定画的是哪一刻的光

从时段、天气、季节和受光方向中选择真正影响本图的条件。说明哪些区域被照亮，哪些处于阴影、反射或雾气中，以及这些变化怎样穿过整幅画。给出一个主导的光色关系，再安排局部变化。

例如，低斜阳可使浅色墙面偏奶黄、背光处偏蓝紫，临水处又染上绿与天色；阴天可用较接近的明度和细微冷暖分出距离。它们是构思示例，不是固定的“亮部黄、暗部紫”配方。暗部可以深，阴天可以灰，晴日也有沉着的色块。

不要先把所有物体按固有色完整画好，再统一罩一层粉色或金色。选择属于本次环境的颜色，让它们以不同面积和强度出现在主体、地面、水面及背景中。光应改变形体的读法和相邻颜色的关系。

## 按光照建立本次工作色板

先选时期、场景与光照，再选主色群、受光色、有色暗部和局部浓色。用户指定配色或源图中需要保留的肤色、衣物与产品色时，在允许改变的区域中协调环境与光照；不能为了“莫奈色系”改掉保留项。

下面是依据本文光色方法推导的**创作方向**，不是从原作采样的色卡，也不是莫奈通用的颜料表。按实际场景选一个方向并具体化，不把所有颜色同时装入一幅画：

| 情境方向 | 可以建立的颜色关系 | 让色板进入绘画 |
|---|---|---|
| 斜阳下的田野或浅色建筑 | 奶黄、赭金与较冷的蓝紫、绿灰相邻，局部留暖亮色与有色深暗 | 让受光色落在朝光的形体与地面，冷色进入背光与间隙；少量邻色笔触穿过大色群，不能逐物平涂 |
| 阴天、蒸汽或湿润城市 | 灰蓝、紫灰、石色与暗蓝绿形成较近明度，暖赭或衣物色集中出现 | 让空气使部分边缘相融，较稳定的深色结构维持空间；灰中仍有冷暖和下层色，不罩一层白雾滤镜 |
| 水园与植被倒影 | 黄绿、蓝绿、深绿、紫灰与映入水面的天色相互穿插，花色按实际主体选择 | 区分岸上植被、垂向倒影和横向水面笔触；反射与被反射物保留色彩关联，水波打断它们 |
| 晚期大面积水面 | 可从深蓝绿、紫、橄榄色与玫瑰色、淡亮反光构成疏密关系 | 用较长、叠压的笔触和较宽色群组织水面，允许深色占明显面积；具体范围按下文晚期分支处理 |

先用颜色名称和明暗关系描述工作色板；用户要色卡或精确沟通时，可补充少量 HEX 锚点，并标为本次近似配色。若实际从某件作品的数字复制品取色，标出作品链接与取色区域，不能称为原作颜料真值。调整色值、补充暗色或亮色时与来源原值分开说明。

每个关键色都要有载体和作用：哪片景物占主面、哪里受光、哪里形成暗隙、什么小面积浓色吸引注意。色板控制大色群的关系，不限制画面只出现这些色号。为各色群选择相邻、交叠的笔触色与可透出的下层色；阴影吸收环境的颜色，反射延续景物与天色，再被水面笔触切断。中间色来自这种绘画组织，不能把色板做成几块平涂或套在照片上的统一调色滤镜。

同景系列中，重新判断各时刻的受光面积、色温、明暗和可见边缘，再调整工作色板；不能只替换 HEX。晚期方向可以采用不同的深浅与彩度关系，不强制沿用早期风景的浅亮比例。

## 把色群组织成画面

先确定大的明暗与颜色区域、视觉重心和视线经过的路径，再将它们拆为笔触。一个主体、几个重复形体或大面积水面都可以支配画面；不强制居中、对称或前中后三层模板。

| 决定 | 具体做法与观察标准 |
|---|---|
| 整体光色 | 安排主要颜色由哪些区域承载，受光与背光怎样区别；缩小看时应先读到统一的光照和大色群 |
| 相邻颜色 | 同一片草地可含黄绿、蓝绿、赭色与紫灰笔触，比例由光照决定；颜色仍能在局部辨开，同时合成一块景物，不能把每处都涂成彩虹 |
| 阴影与深色 | 用与环境相关的有色暗部维持重量和间距；允许局部深褐、深绿或近黑色，不凭“莫奈不用黑”这类绝对说法删掉必要反差 |
| 边缘 | 光、雾或相近颜色使部分边界相融，关键转折、接触或反差处重新显现；不全图统一描边，也不全图均匀模糊 |
| 空间与体积 | 用遮挡、尺度、色温、明度与笔触密度形成距离；物体由相互作用的色块获得体积，不默认塑造光滑、完整的雕塑式明暗 |
| 重点与疏密 | 给花簇、闪光、桥线或主要形体留足可辨认信息，其余区域减少竞争；宁静来自组织，不等于把所有颜色漂白 |

高彩度的小笔触可以落在较安静的大色群中。先调面积、邻接与明度，再调整综合色彩；不以全图高饱和或柔粉滤镜代替光色设计。

## 笔触必须在构造景物

采用可见、长短宽窄不一、相邻或交叠的油彩笔触。下层颜色可从间隙透出，上层轻扫或较厚的落笔形成局部起伏；画面有反复组织的层次，不必伪装成一次快速完成的写生。

根据当前部位分配笔触，具体方向可随景物与构图改变：

| 部位 | 可采用的笔触组织 |
|---|---|
| 水面 | 横向短笔与较长的色带交替，明暗和长度随距离变化；水波切断反射，局部闪光沿水面排列 |
| 倒影 | 保留与岸上形体的大致位置、色彩和延伸关系，再由水波打断；不要生成清晰倒置照片后只降低透明度 |
| 草叶、树冠、花簇 | 用簇状、斜向或下垂的笔触组织生长与光斑，局部重叠，保留较安静的暗色间隙；不逐叶描完，也不铺满等大的圆点 |
| 建筑与桥 | 用较稳定的方向笔触保留主要结构，边缘随光色有断续；窗、栏杆或立面只画支持辨认和节奏的部分 |
| 天空、雾气、蒸汽 | 用相近颜色的较宽笔触、薄层和局部叠色形成空气，内含变化；雾可遮住部分轮廓，不需要滤镜光晕或摄影散景 |
| 人物、衣物与小物 | 用少量互相衔接的色形说明姿态、受光和接触；必要识别点更清楚，但不突然变成贴在画上的高清照片 |

厚薄、笔触宽度和疏密要随区域分工。油画质感来自这些有方向的绘画动作，不能依赖全幅同一种刮刀厚膏、规则点阵、画布网格或人工龟裂。柔和的整体可以包含清楚的笔触；局部粗放也不能以随机涂抹替代构图。

## 合适时主动体现具体的莫奈特征

先检查题材提供了什么机会。以下母题和观察方式可直接使用，也可随新内容变化；不必等用户逐项指定。使用机会是本 Skill 的创作建议，不是艺术家固定的象征释义。

| 特征与依据 | 合适的机会 | 让它在画中发挥作用 |
|---|---|---|
| 睡莲、水草、柳影与天空倒影；《日本桥》，1899，及睡莲作品 | 池塘、庭园、倒影、安静停留 | 用横向浮叶和花簇标出水面，以垂向树影和天光形成另一层；花与倒影有疏密、间距和轻重，而非花纹贴满画布 |
| 弯拱桥穿过繁茂水园；《日本桥》，1899 | 连接两岸、园中路径、经过与停留 | 让桥弧与水面色带形成方向关系，保留栏杆的主要节奏；颜色与周围植被交换，不画成置于背景前的硬边模型 |
| 麦垛等重复形体在变化的光中显现；《麦垛》系列，1890–91 | 田野、季节、时间，或同一对象的连续观察 | 用相对稳定的形体和不同受光面比较光色；新题材可用其他适合的重复对象，不能仅复制麦垛剪影后更换底色 |
| 蒸汽、空气与现代建筑交织；《圣拉扎尔车站》，1877 | 车站、工业空间、出发与城市生活 | 保留支撑空间的主要几何，让蒸汽和有色空气穿过它、遮挡它；机械细节服从光照与可见程度 |

用户强调“更像莫奈”时，提高相关母题、光色关系和笔触组织的可见程度。题材不容纳这些物件时，主动运用相容的观察方式与绘画表现；不往所有场景里补睡莲。只有睡莲、花园或柔和颜色，也不足以判断风格已经成立。

## 晚期睡莲与系列作品的选择

**晚期睡莲方向**：用户要求时，可参照 1914—1926 年的大型水面构图。将视线放向水面，减弱或移出岸线与地平线，让天空、云、植被与倒影在同一片画面中交织；浮叶和花簇标出水面位置，较长、叠压的笔触与较宽色群承担节奏。允许更强的深色、更自由的边缘和接近抽象的部分，不能默认只有淡粉蓝。无地平线不等于没有层次；这也不覆盖全部睡莲时期。

**同景系列**：用户要多幅时，保留能比较的视点和主要形体，再改变时刻、天气、阴影、空气与反射。变化必须影响实际颜色、可见边缘和受光区域，而非只给同一张图换滤镜。用户只要一张时，不自动扩成套图。

## 海报文字按成品单独设计

画作默认无字，不添加签名、馆名或展览信息。海报文字属于本 Skill 的设计适配，不能称为莫奈的固定字体。用户未指定海报语言时可采用简短英文；用户给定文案逐字保留。

字形可选有呼吸感的衬线、圆润手写或流动字标，整组文字的大小、位置与行进方向由画面决定。让文字落在笔触较安静、反差足够的位置，避免压住关键光斑与反射；不因主题是油画而将字也处理到无法阅读。

## 编排实际提示与检查成图

调用前确定本次的时期方向、主体情境、光照时刻、已选工作色板及其大色群载体、可用的具体特征、空间关系、各部位笔触以及必须保留项。特别说明哪些小形体合并为色群、哪些边缘相融、哪些短笔保留辨认；只写“松散笔触”仍可能得到逐件描清的插画。将选择组成完整提示，不转发整篇 Skill 或母题菜单。

提示可按“成品与时期 → 场景及光照 → 大色群与构图 → 各区域的笔触和边缘 → 文字或无字 → 内容约束”组织。可使用 interwoven strokes of neighboring colors、broken reflections crossed by horizontal water marks、selectively lost and found edges 等具体短语，并指明它们作用在哪里。艺术家名字负责定位，实际画法仍需说明。颜色段写出已选颜色名称（需要时附近似 HEX）、占主要面积的景物、受光与暗部，以及哪些邻色笔触和下层色构成它们；不要只写“Monet palette”或把上表全部交给模型。

生成后实际看图，分别检查：

- **光色与色板**：缩小后能否读到同一个时刻的光；所选主辅色是否由指定景物和光照区域承载，面积与明暗重心是否成立；局部能否看到邻色与下层色共同构造景物，阴影与反射是否和环境相关。没有用粉彩、金色滤镜或逐区平涂代替光色关系；用户保留色未被擅改，不按像素是否等于 HEX 判断油画完成。
- **笔触与形体**：正常尺寸能否看见不同部位的笔触方向、宽窄和疏密；它们是否形成景物，而非附在照片表面的一层纹理。
- **空间与边缘**：反射是否仍属于相应水面和景物；轮廓是否有清楚与相融的分工；空气感是否仅来自整体模糊。
- **风格与内容**：具体特征是否适合主题并发挥作用；主体、数量、身份和文字是否保留。不能因画里有睡莲或笔触就直接判风格通过。

遇到偏差先核对实际提示与输入。像照片滤镜时，重写色群和形体的笔触构造；像彩色碎屑时，恢复大色群并减少竞争细节；像规则点彩时，改变笔触长度、方向和交叠；像奶油般厚涂时，明确薄层与局部厚笔的分工；水面混乱时，先修正浮叶、反射与水波的关系。每次只改有证据的原因，保留已有效部分；同一问题两次有目的修正仍无改善时，重新判断方法或说明限制。

交付实际成图、实际提示与重要不足；文件保存到本次项目或用户指定的输出位置。一次示例有效不等于照片身份、海报文字、晚期分支或其他图像模型都已验证。

## 原作与研究依据

以下链接用于核对，不是运行所需图库。正文将作品观察转为制作建议；不声称还原颜料配方或艺术家全部时期。

- [NGA：《日本桥》，1899](https://www.nga.gov/artworks/74796-japanese-footbridge)：桥、水草与倒影的方向关系，绿调中的局部色差。
- [芝加哥艺术博物馆：《麦垛：夏末》，1890–91](https://www.artic.edu/artworks/64818/stacks-of-wheat-end-of-summer)：相似形体的尺度、光照与有色阴影；系列中的比较方式。
- [芝加哥艺术博物馆：《麦垛：秋日黄昏》技术报告](https://publications.artic.edu/node/135601)：相邻与交叠笔触、下层色彩和反复调整共同构成画面；不能把印象派等同于单次快速涂抹。
- [奥赛博物馆：《圣拉扎尔车站》，1877](https://www.musee-orsay.fr/fr/oeuvres/la-gare-saint-lazare-10897)：馆藏说明强调现代空间中的光色、蒸汽与可见程度，拓展水园以外的题材。
- [MoMA：《睡莲》，1914–26](https://www.moma.org/collection/works/80220)：无地平线的大面积反射、植被与自由笔触，用于晚期方向的范围区分。
