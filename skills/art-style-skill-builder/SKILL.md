# 从艺术作品构建风格 Skill

把一个艺术家、时期或流派的视觉语言，转成另一个创作 Agent 能独立执行的 Skill。交付应帮助它做出新的作品，而不只是复述艺术家名字、罗列形容词或复用著名道具。

**核心产物是一套可观察、可操作、可修正的视觉决策。** 用原作建立依据，用实际提示连接执行，用成图检查判断；风格一致与题材自由同时保留。

## 确定研究边界

从用户请求确定艺术家/流派、时期、媒介、目标成品及已有认可或否定。没有指定时期时，选择能支持当前用途的明确范围并说明假设；跨度会改变目标且无法判断时才提问。不要把艺术家的一生压成单一配方。

区分用户要的是风格分析、提示词、可安装 Skill，还是 Skill 加真实试图；只做已授权的交付。创建或大幅改写 Skill 时，可用当前环境可用的技能创作工具校验结构，但方法本身不依赖专属插件。

更新已有方法时先整理：

- **保留**：用户已经认可的视觉效果、目标与内容不变量。
- **替换**：已经误导执行的表达、构造方式或默认选择。
- **忽略**：被后续纠正覆盖的旧要求、与当前用途无关的历史约束。

保留所有仍有效的要求，不让最后一次局部纠偏覆盖整套目标。

## 先看原作，再形成判断

优先用博物馆、艺术家基金会、档案、出版社或作品目录核对作者、年代和媒介，并直接查看足够清晰的作品。选择能显露差异的作品：常见构成、同一时期的另一种组织、容易与它混淆的情况；数量以能支持判断为准，不凑固定配额。

只有文字资料时，将视觉判断标成待看图确认，不能声称已经观察。网页缩略图、扫描件、再版海报的色偏、纸纹或锐化可能属于复制媒介；不要据此断言原作表面。原作、后人仿作、AI 生成图和用户认可图分别标清。

在工作记录中保留简短的“依据 → 判断 → 执行含义”，不把研究日志塞进公共 Skill。对影响默认值的关键判断，留下可追溯的作品或资料链接。分清以下来源：

| 类型 | 如何处理 |
|---|---|
| 原作中可见的事实 | 说明在哪件作品里看见了什么，不扩写成所有作品的定律 |
| 跨作品推断 | 标明是归纳；找变化和边界，决定是否足以成为默认 |
| 用户审美偏好 | 在适用成品中保留，不能冒充艺术史事实 |
| 成品适配 | 海报字体、画幅、印刷再现等可由设计者新增；与原作语言分开说明 |
| 单次生成现象 | 先诊断实际输入、提示和成图；不直接写成普遍风格禁令 |

## 拆解关系，也保留具体辨识特征

下表是观察视角，不要求每个艺术家都有对应规则。保留真正改变创作决定的部分。

| 维度 | 要回答的具体问题 |
|---|---|
| 主题与造型机制 | 内容怎样被选择、变形、并置、重复或省略？情绪来自什么可见关系？著名符号如何参与其中，还有什么可迁移的方法？ |
| 具体辨识特征 | 哪些形态、物件关系、动作或色彩组织有明确辨识度？出自哪个时期、哪些作品？什么情境值得主动采用，怎样融入主题？ |
| 构图与视线 | 视觉中心如何形成？人物看向哪里？尺度、裁切、姿态、节奏如何分配？局部结构对称与全画镜像是否不同？ |
| 空间与体积 | 正面排列、透视、遮挡、前后尺度、空气远近分别做了什么？浅空间是否仍保留真实体积和材料？ |
| 媒介与表面 | 是摄影、油画、版画还是混合再现？形体、光色、表面和信息密度各有多写实？边缘、笔触、颗粒、光泽与细节取舍怎样统一主体和环境？ |
| 光色关系 | 光从哪里来？大面积主辅色、浅底、深色支点与点缀各由什么承载？冷暖、明度、彩度和综合色调怎样共同起作用？ |
| 字形与文字构图 | 原作是否依赖文字？新增字体的骨架、粗细、连笔、字距是什么？整组沿何种路径排布，与主体如何相处？ |
| 变化范围 | 哪些关系稳定，哪些随主题变化？哪些只属于某时期、某媒介或用户选择？ |

写规则时建立三层：**识别骨架**是失去后会换风格的关键关系；**默认选择**是本 Skill 采用的一个制作方向；**可变区域**留给本次主题和用户。骨架来自证据，不能凭喜好将每个细节升级为硬规则。

在这三层中保留有依据的具体辨识特征，不要将风格提炼到只剩通用构图、变形和色彩建议。为可选特征写清“可见形态 → 合适情境 → 在画中承担的作用 → 如何与新内容连接”，并标明作品时期；情境映射属于创作推导时应说明。可选表示不强制每图出现，不表示创作时忽略它。题材提供机会或用户强调风格辨识时，应主动选择相容的特征，无需等用户逐件点名。原有母题可以直接采用，也可围绕新题材变化；不为避免套路而一律抽象掉，不为像某艺术家而堆砌符号。用户内容约束与指定时期仍优先，不设固定道具数量或必备清单。

每条重要规则都应完成这个转换：

> 在作品中看见什么 → 它产生什么效果 → 新题材中具体怎样安排 → 看图时怎样判断是否发生。

例如，“空间浅”要落实到观看方向、前后尺度和遮挡；“颜色协调”要落实到组合、载体、面积和调色；“材质像胶片”要联合检查影调、边缘、颗粒与再现表面。不能把这些例子的具体风格设为所有艺术家的默认。

同时检查维度间的冲突：压缩空间不等于删掉材质；油画不等于厚涂；写实建模不等于数码摄影；有颗粒不等于胶片；提高色彩区分度不等于全图加饱和；艺术字不等于不停加花饰。遇到宽泛词，改写它在当前媒介里的物理表现。“精细”要说明精确的是轮廓、比例、色层还是表面纹理，并指定精细给哪里、哪里概括。艺术家可以精确塑造体积，同时省略材料细节；也可以在光色概括的形体周围安排密集环境。不要用单一“写实程度”覆盖这些不同选择，也不要遇到 CG 偏差就自动添加粗笔触。依赖多个读法的视觉关系，要检查每一种身份能否独立成立，而不只是抽象名称被画出来。

## 建立色彩方法与工作色板

色板是一组供本次创作选用的颜色及其关系；它不能单独代表艺术风格。先确定所研究的时期、媒介和光照范围，再决定是否需要固定色值、命名色板或只有颜色关系的工作方案。艺术家跨时期变化很大时，按适用范围分别组织，不拼成一张“终身通用色卡”。

### 先分清颜色从哪里来

| 来源 | 应记录与说明的边界 |
|---|---|
| 从原作的数字复制品取色 | 链接具体作品与实际使用的图像，说明取自哪一片可见区域。取到的是这份复制品的显示色；光照、拍摄、扫描与色彩管理会改变数值，不能称为原作颜料配方或现场真值 |
| 已发表的命名色板 | 保留来源、色板名称、准确色值及适用范围；需要随包分发时保留相应许可。区分官方资料与社区整理，区分离散选色、连续色阶和用于整体变换的调色表（LUT） |
| 从作品观察推导的工作配色 | 明确是创作建议。可用颜色名称、冷暖、明度和彩度描述；只有需要更精确沟通时才给近似 HEX，不能把自拟数值称为采样结果 |
| 用户指定色板或源图保留色 | 保留指定色值及身份、肤色、产品等颜色约束，在允许改变的区域中适配风格。未经说明不以风格默认覆盖它们 |

将来源色值与后来调亮、压暗、降彩或补充的颜色区分开；需要交付色板时一并标明。命名与顺序不自动表示视觉主次、面积或颜色用途；没有明确来源时，不编造“艺术家官方色板”。

### 从色板走到画面

先看大色群的色相、明度和彩度，再看面积、位置与相邻关系。按当前画面选择主色、辅色、受光色、有色暗部、点缀，以及确有文字时的墨色；这些是可用角色，不是每图必须填满的栏目。指定每个重要颜色由什么实体、材料或光照区域承载，哪里占大面、哪里集中、哪里退后。没有依据时不固定面积百分比，也不要求用完色板所有颜色。

随后把颜色转成当前媒介的制作动作。摄影海报可能需要布景与衣物配色、肤色保护、影调和印刷再现；光色绘画可能依靠相邻笔触、下层透色、阴影与反射；精确造型的油画可能用完整亮暗面和连续色阶构成体积。三者的色值即使相近，执行方法也不同，不能统一套一层柔暖胶片滤镜。

工作色板应允许材料、照明和笔触产生合理的邻近色与中间色。HEX 是沟通锚点，不是要求生成图每个像素严格落在色卡中；也不能将数字混色直接等同于真实颜料混合。明亮、深暗或高彩度都按作品依据与本次场景决定，不为“高级感”一律洗灰或漂白。

若成套命名色板确有反复调用价值，可放入单独的文本参考，正文写明何时读取、如何选择和如何使用；必要数据本地可达，不引入下载图库或专用软件的运行依赖。少量创作方向直接写在正文，避免为每位艺术家机械建一份无来源 HEX 表。

### 提示与成图要检查同一套颜色关系

实际提示选择一个已决定的配色方案，写出颜色名称（需要时附色值）、具体载体与面积关系、受光和暗部、媒介如何构造这些颜色，以及必须保留的颜色。给出了色板名称也仍要写可见安排，不能只让模型自行理解名字；不把整张色表或备选菜单当作场景内容。

检查时先缩小看主辅色、明暗重心和冷暖关系，再看局部材料、笔触、反射与文字。逐项确认：颜色是否出现在指定的大区域；重要色相是否被整体调色吞掉；身份色是否保留；中间色与暗部是否仍构成当前媒介。不要只数颜色、核对某个像素或看到相似色块就判断风格通过。颜色互相冲撞时先查面积与邻接，发灰时查是否过度罩色，空间扁平时查明暗与媒介构造，再调整相应部分。

## 把方法写成可独立调用的 Skill

正文只保留创作时会用到的知识，组织方式随艺术语言而定。通常需要：

- 明确的风格时期、媒介、适用成品和可覆盖默认。
- 从文字、照片、正面风格参考或失败图进入的不同处理；哪些内容必须保留。
- 关键造型、构图、材料和光色关系，以及允许变化的空间。
- 调用图像工具前应做出的本次设计决定。
- 以成图为对象的检查和有因果依据的修正方式。

参考图不应成为运行依赖。把必要风格知识写在文字里，公共包默认不带图库、私人路径、特定客户题目或测试图。大量条件性资料确实有用时才拆成有明确读取时机的文本参考。

不要照抄前一个艺术家 Skill 的章节配方：摄影导演的浅层布景、暖色胶片与标题排版，不能自动成为画家的造型、颜料和空间规范。保留研究方法，重新选择风格内容。

对于原作没有稳定字体语言的艺术家，正文明确“文字是目标成品的设计适配”。先决定是否需要字，再决定字形和整组构图；不能根据艺术家名字杜撰固定字体。用户的英文、圆润字、连笔字等偏好只在相关用途里生效。

## 编排真正交给图像模型的提示

由当前请求和 Skill 做出完整构想，再编排实际提示。不要整篇转发 Skill、反馈记录、分支菜单或未填模板。

实际提示通常说清：成品与媒介；本次主体与情境；关键变形或关系；构图和空间；材料及光色；需要时的精确文字与排布；内容保留项。选择具体辨识特征后，将它在本次内容中的形态、位置和作用写进提示，不能只写特征名或把选项清单交给模型。数量、方向、尺寸、字号比例和留白不能互相矛盾。无需每次填满所有字段。

为图像输入逐张指定角色：

- **编辑目标**：修改这张图；列出允许修改的部分与必须保留的部分。
- **身份/内容依据**：约束人物、产品或建筑特征，不自动继承其风格与布局。
- **正面风格参考**：借用指定的视觉关系，不复制其中的题目、演员、标识或原样构图。
- **失败图**：供诊断；用户要求改它时才作为编辑目标，不作为正面风格输入。

在当前工具支持的参数中实际传入应使用的图像；仅在文字里说“参考附件”不等于完成传图。具体工具和参数以运行环境为准，公共 Skill 不硬编码某款应用的私有接口，也不自动改模型或转付费路径。

正向提示优先描述想要的可见结果；负向约束只针对本次容易混淆且重要的问题。不要把所有历史失败词反复放入正常提示。

## 用成图检验，并定位失败层

有真实出图授权和工具时，先用一个能检验关键风格关系的新题材生成。需要判断可迁移性时，再换题材、场景或主要造型机制，避免仅更换一个道具却宣布已泛化。若只获准分析或写提示，交付文件并明确视觉尚未验证。

查看正常观看尺寸的整体效果与必要细节。先看用户保留项和识别骨架，再看本次情境、空间、材料、光色和文字；不能只检查“画里有没有某个物件”。同时检查是否因过度抽象错失了合适的具体风格特征，已选特征是否在画中发挥作用；只剩泛化氛围或只有符号堆叠都需要重新判断。双重图像要看两种读法，文本要逐字看，身份转化要对照源图。

分别判断“主题或造型机制是否成立”与“艺术语言是否成立”。变形、对称或符号正确，但明暗组织、表面和细节分工偏离原作时，不能判定风格通过。校准新的绘画表达时，可在相同题材下用新提示生成，避免旧失败图的材质继续支配编辑；这只在无需锁定原图内容的验证场景适用，不改变用户要求编辑原图的任务。

保存实际提交的提示、实际输入角色、成图及简短判断到本次工作目录。区分“工具运行成功”“可见效果满足规则”“用户认可”，三者不能互相代替；也不能把一个工具的成功宣称为另一个工具已测。

遇到偏差按证据定位：

| 失败层 | 优先检查和处理 |
|---|---|
| 目标理解 | 用户要求是否被错译、旧纠偏是否已被覆盖；更新本次目标，不扩大成新风格定义 |
| 规则归纳 | 是否把单幅或复制品特征当规律；回原作修判断，保留已有效部分 |
| 提示编排 | 实际提示是否遗漏、歧义、冲突或比例不一致；写清造型和物理机制，不只加形容词 |
| 输入/工具执行 | 是否读错文件、使用旧版本、漏传图、混淆参考角色或走错生成/编辑路径；先修执行链 |
| 生成能力 | 上述输入清楚但仍没有实现；减轻相互竞争的约束、定向编辑或说明限制，不能假称已经成功 |

每轮先写一句可验证的原因假设，再改最相关的部分，复查有没有破坏原先有效的效果。同一问题两次有目的修正仍无改善时，停止叠提示，回看假设和可用编辑路径；不能把失败输出降低标准后说成通过。

反馈进入公共规则前判断作用域：它改变的是艺术家规律、成品默认、用户偏好还是当前案例。只提升有依据且可复用的部分，合并重复说明，移除被替换的旧表达；失败例只留下必要诊断，不堆成长期禁词库。

## 完成与交付

检查 Skill 的名称和触发范围准确、入口自包含、必要参考可达、没有未填占位符；可用时运行环境的 Skill 校验器。结构通过只能证明包装可读，不能替代创作测试。

交付技能入口和可移植文件；有试图时同时给成图、实际提示及具体不足。说明此次研究与验证覆盖的时期、媒介和能力。目标满足且有相应证据即停，不为证明流程增加固定用例数、复杂评分系统或额外协调设施。
