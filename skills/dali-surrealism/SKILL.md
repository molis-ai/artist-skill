# 达利：精确描绘的不可能世界

用精确的轮廓、经过概括的明暗和主动变形的形体，呈现一个熟悉而不可能的世界。让造型承担主题，使观看在辨认与不安之间停留。

**本 Skill 以达利 1930 年代的幻觉式油画语言为基础：轮廓与体积精确，形态主动变形，色面与细节经过明确取舍。** 主体可有雕塑般平滑的明暗，却保留梦中才有的比例、连接和形态；材质识别服务于这种造型。空间可以辽远，局部可以精细，大面可以安静。题材合适时，主动采用有辨识度的达利母题，使其参与主题与构图；不要求每张画出现同一套道具。下文也纳入明确来自 1946 年作品的细长动物承载建筑母题；用户限定时期时遵从对应作品范围，不将不同时期混称为一种配方。

## 输入与默认交付

默认从用户主题生成一张无字画作；横向题材可用 3:2，其他画幅由内容或用户要求决定。交付成图与实际使用的提示词；只要提示、分析或评审时，停在相应产物。用户明确指定的媒介、时期、构图、文字和画幅覆盖相关默认。

- **简短主题**：把情绪或命题变成一个物体关系，再选择必要的环境与尺度。可以补足情境，不能用无关奇观填空。
- **详细描述**：保留指定对象、数量、动作和边界；超现实手法作用于允许变化的部分。
- **照片转化**：先看源图并作为图像输入。人物身份、年龄外观、肤色、产品结构、建筑识别点与明确保留项不因风格化自动变形。若用户只说“达利风格”，先让周围空间、影子或非身份性物件发生变化；用户明确要求变形主体时再作用于相应部位。
- **正面风格参考**：提取指定的光色、形态或绘画表现；不照搬原作布局、作品名或签名。
- **失败图**：用于检查偏差；只有用户要求改它时才作为编辑目标，并列出保留与替换内容。

本 Skill 不依赖参考图库。没有附件也能按文字方法创作；不自动调用历史用户图片。必要源图缺失或保留要求冲突时才澄清。

## 1. 先选一个支配画面的不可能关系

先看题材能自然容纳哪些有辨识度的达利特征，再确定它们如何构成主题所需的变形关系。不要将“标志物不是必需”理解为应该避开标志物；只有抽象的怪诞、拉伸或荒凉，还不足以形成明确的达利方向。下列方法可择一主导，再用少量辅助关系呼应；不需要每张图同时出现全部方法。

| 方法 | 具体设计决定 | 成图中应看见什么 |
|---|---|---|
| 软硬互换 | 哪个原本坚硬的物件失去刚性；何处被托住、受拉、折弯或下垂；哪些边缘仍让人认出原物 | 材料身份与不可能的柔软同时可读；弯曲有连续厚度、褶皱、重力和接触，不能只是液滴融化特效 |
| 形态转化 | A 的哪条轮廓或哪个结构逐渐成为 B；连接位置、大小和材料如何连续 | 两种身份在同一形体上过渡，不能只是把独立物件摆在一起 |
| 双重图像 | 同一片轮廓、空隙或明暗如何分别读成 A 与 B；逐项设计共享部位 | 两种读法都在同一图像中成立；不是半透明叠图，也不是物体旁边额外画一张脸 |
| 尺度与支撑失衡 | 什么巨大、什么细小；支撑点在哪里；是否悬浮以及影子离主体多远 | 重量、脆弱与距离可比较；明确接触位置、压力与投影即可支持重量感，不必增加表面纹理 |

变形可以克制，也可以占据全画。用情绪决定幅度：等待可以呈现被拉长的间距，疲惫可以呈现硬物失去支撑，记忆可以呈现形态相互侵入。这些是创作推导示例，不是固定道具和主题映射表。

### 合适时主动采用具体母题

母题是可反复变化使用的形象或物体关系。下面列出有原作依据的选择；“使用机会”是本 Skill 的创作建议，不是达利对这些形象的固定释义，也不是封闭清单。

| 具体特征与作品依据 | 可以主动考虑的情境 | 如何让它真正参与画面 |
|---|---|---|
| 可辨认表盘的软钟表；《记忆的永恒》，1931 | 时间、等待、衰老，或秩序失去刚性 | 保留表盘与指针，让表身在与主题有关的边缘上折弯、被托住或下垂；写清厚度与受力，使它成为主要关系的一部分 |
| 巨大软形体与细弱的叉形木支撑；《睡眠》，约 1937 | 疲惫、依赖、维持平衡，或勉强支撑的事物 | 将支撑放在实际承担重量的位置，以细小接触和巨大体量形成张力；不是在物体旁边摆一根无作用的木棍 |
| 蜘蛛般细长的动物腿承载庞大身躯与建筑；《圣安东尼的诱惑》，1946 | 负重、迁徙、野心，或携带着一个世界前行 | 让腿部的长度、纤细与上方体量产生鲜明比例差，建筑与背部有明确承接；用接地、投影及远近比较维持重量感。动物和所承载内容可随题材变化 |
| 身体、石形、器物与景物之间的形态呼应和共享轮廓；《纳西索斯的变形》，1937，以及《海滩上面孔与果盘的幻影》，1938 | 自我、记忆、身份转变，或一个事物中显露另一个事物 | 选择可画出的弯曲、孔隙、外轮廓和明暗，将它们用于对应形体；若要求双重图像，两个读法须按下文分别成立 |

优先选择既能服务当前主题、又能加强风格辨识的特征。用户强调“更像达利”或“风格明显”时，主动提高这些具体形态与绘画组织的可见程度，不等用户逐件指定道具。原有母题可以直接使用，也可以围绕新内容转化；无需为了原创而强行换掉所有熟悉形象。主题、用户保留项或指定时期不适合时，采用相容的造型和绘画关系，不硬塞符号。空旷海岸、长投影与冷暖远近可共同支持这种语言，但不能独自承担全部风格辨识。

允许改变物体的比例和外轮廓，使其成为能辨认来源、又无法完全还原成日常物件的形体：某一部分可以拉长、收细、膨大、折返或与另一种形态相接。保留辨认所需的关键结构，而非自动保留产品级完整结构后仅添加一个特效。照片身份与用户明确要求保真的部分仍按输入约束处理。

双重图像难度高，只有主题需要才使用。先写出两个读法及共享结构，再检查每个共享部位作为第一种物体能否独立成立：墙柱仍应像墙柱，不能直接做成鼻子浮雕。实际提示先描述可画出的轮廓、开口、接缝与明暗，再说明第二读法；若只是“看起来像脸”，还没完成几何设计。不能生成后看到偶然轮廓，便反过来宣布达成了指定的双重图像。

## 2. 让空间和尺度放大那件事

安排视觉主体、承托面、远处环境及它们之间的距离。常可用空旷平原、海岸、建筑内部或不合理延伸的日常空间；不强制沙漠，也不自动让人物居中正视。

主体位置由张力决定，允许偏心、不对称和大片空处。精确安排不等于左右镜像。地平线、遮挡和尺度变化共同制造可走入却无法抵达的距离；前景形体可以异常巨大，小物或远处形体提供比较，但不为比例尺强行添加无关人物。

需要辽远时，让近处结构清楚、远处减弱反差与细节，地面连续退去。不要用摄影浅景深把远景抹糊来代替空气远近。天空和地面可以占大面积，但内部要有细微色阶；空处承担寂静与等待，不是随手留下的填色区。

场景密集时，让共享轮廓、重复形状或光线形成读取顺序，不以增加奇怪物件代替组织。

## 3. 绘画组织：精确造型，概括大面

先把画面看成相互安排的形体、亮面、暗面与空处，再选择局部细节。主体的明暗可以平滑、细腻，转折可以有雕塑感；其亮暗分区和色彩过渡经过主动概括，让形体在大面积安静的色面中显现。清楚的绘画表现不依赖粗笔触。

“精细”主要指轮廓、比例、形态连接和少量关键细节的准确。每次构想都应确定哪里精细、哪里概括：关键褶皱、睫毛、裂口或交接处可以耐心画；地面、墙面、皮肤与天空不需要同样密集的信息。复杂题材也可有细密背景，但要与较概括的形体或空处形成分工，不能把所有原作归纳成一律少细节。

| 部分 | 如何描绘 |
|---|---|
| 主要轮廓 | 关键形体清楚，以拉伸、弯折、膨大和收细形成节奏；边缘随背景与受光有收放，不给全画统一描边 |
| 体积 | 用较完整的亮面、半明面和暗面，再在转折处细腻过渡；软化部分仍有厚度，体积不能因减少纹理而消失 |
| 材料 | 以形状、固有色、少量反光或折痕表达材料身份。必要处有触感即可，纹理不应遮盖外轮廓和明暗结构 |
| 光线 | 用清晰的受光和投影组织形体、间距与寂静；投影可形成大而简明的暗形。光色支持共同场景，不要求模拟每一处真实反射和微小凹凸 |
| 大面与细节 | 大面通过薄层色调与缓慢渐变保持变化；局部细节集中承担辨认、转化或情绪，避免等密度地描满石粒、裂纹和高光 |
| 绘画表面 | 薄而收敛的处理、微妙色层与有取舍的边缘贯穿全画；不用厚重刮刀、粗帆布、人工龟裂、滤镜或整体模糊代替这种组织 |

若成图像写实道具或 CG 场景，先检查：形体是否仍是未经提炼的日常模型；材料的碎小变化是否占据了注意力；每处光照与纹理是否被同等完整地交代。优先重组外轮廓、亮暗色面和细节分工，再收敛不必要的反光与纹理。平滑本身可以属于这种绘画，不能为了去掉 CG 感而全面加粗笔触。若变成扁平插画，恢复体积转折与选择性的明暗过渡。

## 4. 配色与明暗要共同构成空间

先按时期、场景和主导变形选择本次工作色板，再分配亮暗与远近。用户指定配色、肤色、产品色或源图保留色时优先保留，在允许改变的背景、光照和次要物件中协调。不能用“达利色系”覆盖内容约束。

以下是从本文空间与造型方法推导的**创作配色方向**，不是官方色卡或原作采样值；根据题材选用或另行组合，不要求每张画暖地冷天：

| 方向 | 颜色关系 | 服务的画面关系 |
|---|---|---|
| 明亮地面与冷远景 | 赭石、土黄、骨白与蓝、青灰或蓝绿相邻，深褐或深蓝集中压住关键暗形 | 用大面积地面与空气形成远近，完整亮暗面使异常形体有厚度；天空与地面内部保留缓慢色阶 |
| 暗前景与清朗远处 | 前景采用较深土色、褐红、橄榄或蓝黑，远处留较浅、较低反差的环境色 | 让近处轮廓、长投影与远处空地形成张力；深色服务形体与距离，不把全画一起压黑 |
| 同系形体与局部浓色 | 主体与承托物可共享石色、肉粉、灰绿或其他相容色系，以少量浓红、蓝或暖金形成焦点 | 用连续明暗连接变形，让局部浓色突出接缝、受力或关键身份线索；焦点由位置与面积决定，不给所有物件同等浓色 |

通常用颜色名称、冷暖和明暗即可建立工作色板。需要色卡时可提供少量近似 HEX，标为本次创作建议；实际从数字复制品取色时，写明作品链接和区域，不能称为原作颜料配方。派生的浅色、暗色或新增颜色与来源原值区分。

把所选颜色分配到具体的主体、地面、远景和投影，说明谁占大面、谁从属、最亮与最深落在哪里。随后为关键形体安排受光色、半明面、暗面与转折处的连续过渡；色板限定综合色相关系，不截断体积所需的中间色。投影遵循本次光向，接触暗部与体量共同说明支撑；不靠单一固有色平涂或全画加反光制造“精确”。

形态转化处要保留连续的光照与色阶，使 A 如何成为 B 可读。双重图像要设计共享的亮暗与色块：同一片暗部或轮廓须同时服务两个读法，不能给两种身份各涂互不相干的颜色而拆散共同形体。不同身份可以有色差，但差异应服从共享结构。

阴影可以深、局部反差可以明确，颜色也可以鲜明；静寂依靠大面的组织、面积与细节取舍，不机械套用复古海报的抬黑、柔暖罩色或全画降饱和。出现空间扁平时先恢复亮暗分区和色阶，颜色冲撞时先调整面积与邻接，不能一律用滤镜补救。

## 5. 海报与文字是可选适配

无字画作不额外加标题、签名或说明。用户要求海报时，把达利式图像作为视觉主体，文字按成品目的另行设计，不能称为达利通用字体。

先确定语言与精确文案，再选字形骨架和整组文字的位置、路径与大小节奏。用户未指定语言的海报可采用简短英文标题；这是本 Skill 的海报默认，用户语言要求优先。圆润字、连笔、细长衬线或流动字标都可根据题材选择，不规定每张都融化字母。

字标可以呼应画中某条曲线、拉伸关系或负空间，但完整单词应清楚可读，不能遮住关键双重轮廓。字色从画面已有颜色中选择，保证阅读反差；主副标题有层级，空白与主体共同排布。用户指定的文字逐字保留，不编造展览、馆名、奖项或艺术家背书。

## 调用前形成完整构想

先确定本次的主体与情境，检查可用的具体达利特征，再确定主导变形、具体连接和支撑、位置与尺度、观看方向与远近、所选工作色板及亮暗色面的载体、精细与概括各分配在哪里，以及需要时的文字。选用母题时，说清它为何适合主题、放在哪里、承担什么关系；这些决定应落实为可见构造，而不是只在提示末尾加一个母题名称。材料描述只保留支撑辨认和主题的部分。把这些选择写进实际提示，不把备选机制菜单丢给图像模型。

可按“成品与绘画组织 → 主体及异常轮廓 → 构图与空间 → 亮暗/颜色/细节分工 → 精确文字或无字 → 必须保留项”编排。实际正向提示用 precisely drawn transformed silhouettes、smooth sculptural tonal modeling、broad quiet painted planes 等具体表现，结合本次内容明确精细处和概括处，不能只写 highly realistic / highly detailed / oil painting。艺术家名字用于定位方向，后面仍写清可见做法；不整篇复制本 Skill，不转发历史失败记录。颜色段选定一组颜色名称（需要时附近似 HEX），具体指定大区域、焦点、受光/半明/暗面及过渡；使用形态转化或双重图像时，写出颜色和明暗如何连续或共享，不只写“Dalí palette”。

只选与本次有关的约束。没有名作道具的题材，无需在每次正向提示里重复完整禁词清单。使用照片或编辑图时，按当前工具实际支持的输入参数传入，并在提示中标明每张图的角色；不能只说“看附件”却没有传图。

## 看图与修正

生成后实际查看图像，并按当前任务检查：

1. **内容与异常关系**：原物是否可认；具体变形、共享轮廓或支撑是否发生；有没有用新添的脸、道具或特效绕开核心要求。
2. **风格辨识与题材关系**：哪些具体形态和绘画关系使它可辨认为达利方向；适合题材的机会是否被过度抽象的规则错过。已选母题是否参与内容、尺度或构图，还是仅被加成装饰；有名作道具也不能代替绘画语言检查。
3. **空间与体积**：距离和尺度是否可比较；主体与环境有接触或可信悬浮关系；空处有没有帮助主题。
4. **绘画与光色**：缩小看是否先读到经过组织的轮廓、体积和大色面；所选颜色是否由指定大区域承载，明暗重心、远近和焦点是否成立。形体转折有连续色阶，双重读法共享的色块没有被配色拆开；深色未被统一抬灰，保留色未被擅改，不用像素等于 HEX 代替判断。正常尺寸是否有明确的精细/概括分工。纹理是否抢过形态，整体是否仍像可以搭建拍摄的道具场景；不能只以“有变形”或“没有塑料光泽”判定风格通过。
5. **用户保留项和文字**：身份、数量、结构及明确文字是否正确；海报字标有没有抢走画中的形态关系。

双重图像要分别说得出两种读法在图中哪里发生。只出现一个读法就记未完成，不用“超现实氛围已经足够”替代要求。文字和身份未验证时也应明确标出。

先定位实际提示是否漏掉几何关系、输入角色是否错误，再定向修图。软物像融化特效时，改受力、厚度和褶皱；物件仅并排时，改共享轮廓与连接；画面杂乱时减少竞争机制并理顺尺度；媒介偏差时改材料、边缘与明暗表现。同一问题两次有目的修正仍无改善，说明具体限制并重新判断方案，不无限加形容词。

每轮保留已经成立的关系，不静默改掉用户要求。分别判断“主题与变形机制成立”和“绘画语言成立”；前者通过不代表风格已准确。交付实际成图和实际提示，说明重要不足；一次成功不代表其他模型或所有模式都已验证。

## 范围与原作依据

以下是研究依据，不是必须下载或输入模型的参考图库。上述创作做法包含对作品的观察归纳和本 Skill 的制作选择，不能当成艺术家自述。

- [MoMA：《记忆的永恒》，1931](https://www.moma.org/collection/works/79018)：硬物软化、精细描绘与辽远环境的关系。
- [Gala–Salvador Dalí Foundation：《睡眠》，约 1937](https://catalogues.salvador-dali.org/catalogues/en/heritageobject/280-51f9/)：巨大柔软形体、细弱支撑与空旷空间。
- [Freud Museum 展示的《纳西索斯的变形》，1937](https://www.freud.org.uk/exhibitions/freud-dali-and-the-metamorphosis-of-narcissus/)：概括而有体积的身体与石手、形态呼应，以及细密环境与平滑主体的分工。
- [Wadsworth：《海滩上面孔与果盘的幻影》，1938](https://www.thewadsworth.org/learn/education/virtual-studio/surreal-scenes/)：多个形象共享轮廓和空间，产生可切换的读法。
- [比利时皇家美术博物馆：《圣安东尼的诱惑》，1946](https://fine-arts-museum.be/fr/la-collection/salvador-dali-la-tentation-de-saint-antoine)及 [LACMA 馆方解读](https://unframed.lacma.org/node/2234)：细长如蛛腿的象与其背上建筑形成体量反差；这里仅借用相应母题，不将作品宗教寓意固定套入所有新题材。
- [基金会：绘画时期概述](https://www.salvador-dali.org/en/dali-and-gala/dali-the-total-artist/painting/)：提示晚期核神秘主义与早期超现实油画存在方向差异。用户指定晚期、立体视觉、版画等范围时，按所指定的原作重新研究，不把本默认直接改名套用。
