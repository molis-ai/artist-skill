# 艺术风格元技能：达利试行记录

研究与出图日期：2026-09-11（Asia/Shanghai）。本记录在公共技能包之外；不是给下一次创作必须加载的上下文。

## 最新修订：合适题材主动体现具体风格

用户明确要求在合适机会体现具体风格。诊断：原规则主要防止复用名作道具，没有同等明确地指导何时主动使用，容易将达利方向抽象成通用超现实变形。此次保留已校准的绘画组织，在达利 Skill 加入可见母题、题材机会、画中作用和连接方式，并将选择落实到实际提示与成图检查；元技能只提炼同一原则。

新增来源核对：[比利时皇家美术博物馆馆藏页面](https://fine-arts-museum.be/fr/la-collection/salvador-dali-la-tentation-de-saint-antoine)确认《圣安东尼的诱惑》为 1946 年油画；[LACMA 馆方解读](https://unframed.lacma.org/node/2234)说明蜘蛛般长腿的象及其背上建筑。正文明确该母题属于新增的 1940 年代借用范围。负重、迁徙等应用机会标为本技能的创作建议，不冒充艺术家固定象征释义。

人工审阅本轮选择规则的典型与受约束情境：

| 情境 | 按修订规则形成的具体决定 | 审阅结论 |
|---|---|---|
| 关于等待的无字画作，要求风格明显 | 主动采用可辨认表盘的软钟表，让它越过等待者所在台阶的边缘下垂；表盘、折弯、承托点和投影共同构成关系 | 规则允许直接使用熟悉母题，并要求它承担主题与构图，不只在角落添加一个时钟 |
| 携带家园前行的题材，未限定时期 | 可让动物细长的肢体承载背上的建筑，写清背部承接、腿与体量的比例、接地与投影，并延续概括明暗与细节分工 | 具体达利特征与题材结合；新增年代边界明确，绘画语言未被道具选择替代 |
| 用户要求只采用 1930 年代方向 | 按对应作品选择软硬转化、细弱支撑或形态呼应；不将 1946 年长腿动物与建筑母题列为该时期默认 | 指定时期覆盖跨期借用默认 |
| 产品照片转化，明确保持产品结构 | 保留产品外形与结构，在相容的环境物件、影子或空间关系中体现风格；不为使用软化或拉伸母题而改掉产品 | 内容保留要求仍优先；本轮规则没有变成每图必加的道具清单 |

上述为文档与提示决策审阅，未调用图像生成，不构成新增母题的视觉效果验证。前次真实试图的绘画偏差结论仍有效。两套 Skill 均通过 `quick_validate.py`；source、安装副本与发现入口的实际正文及 UI 元数据内容一致。独立 ZIP 与合并 ZIP 已重建，包内只含各自已审阅的 SKILL.md 和 agents/openai.yaml，未混入用户图片或工作记录。

## 前次修订：用户指出过于写实后

用户提出“达利的风格是不是没有这么写实”，要求网上搜原作，并明确授权修改。重新查看原作后，新增 [Freud Museum 展示的《纳西索斯的变形》](https://www.freud.org.uk/exhibitions/freud-dali-and-the-metamorphosis-of-narcissus/)作为观察依据：主体的身体和石手使用较概括、平滑的体积塑造，周围环境可以细密，细节密度有明确分工。结合此前原作，不能把“精密”直接翻译为全画的真实表面细节。

达利技能已改为“轮廓与体积精确、形态主动变形、色面与细节有明确取舍”，覆盖定位、媒介说明、正常提示编排、视觉检查与 UI 摘要；元技能补充分开判断形体、光色、表面与信息密度的写实程度，并分开验收主题机制与艺术语言。未把达利的具体配方泛化到全部艺术家。

新增一次无参考图片的文字生成，保留同一柔软瓷杯题材，重新设计形态与大面，检验修改后的正常创作路径：

- [实际提示：绘画组织修订版](../../skills/dali-surrealism/outputs/soft-porcelain/poster.prompt.txt)
- [对应新成图](../../skills/dali-surrealism/outputs/soft-porcelain/poster.png)

目视结果：石台由大块明暗和少量裂缝构成，地面信息密度明显下降；杯身延展和收细更强，仍可辨认杯口与把手，支撑和投影关系保留。杯面的高光与光滑材料仍略有 CG 观感，因此本次判定为“规则修改有效、绘画表现部分改善”，不判为风格完全通过。没有继续用粗笔触、画布纹理或循环叠提示掩盖这一缺口。

下方初版试验记录保留作过程证据；其中造型关系通过不等于用户认可风格。当前版本两套 Skill 已通过结构验证，按此修订同步并重新打包。

## 研究判断

直接查看以下官方页面中的原作图像，并阅读相关馆藏说明。没有将原作下载、打包或传给生成模型；试图仅使用新技能编排的文字。

| 来源 | 可见观察及资料核对 | 转化为本 Skill 的决定 |
|---|---|---|
| [MoMA：《记忆的永恒》](https://www.moma.org/collection/works/79018) | 1931，油画。前景软化形体与明确物体身份并存；大片暗地、蓝色远处和暖色岩岸共同构成距离。形体建模精确，构图并非全画对称。 | 不把融化钟表列为必需物件；提炼材料身份、柔软形变与局部受力关系。深色和清楚体积可保留，不套用此前韦斯海报的抬黑与浅空间。 |
| [基金会：《睡眠》](https://catalogues.salvador-dali.org/catalogues/en/heritageobject/280-51f9/) | 目录标为约 1937 年、油画。一个巨大的延展头部由细弱支撑接触，远处建筑与小形体造成尺度差，周围空处充足。 | 将异常大小、接触和脆弱支撑变成可用机制；不强制每张画有拐杖或人脸。 |
| [Wadsworth：《海滩上面孔与果盘的幻影》](https://www.thewadsworth.org/learn/education/virtual-studio/surreal-scenes/) | 1938，油画。果盘、脸与环境共享轮廓和位置；器皿、景物与动物之间可切换读法，画面比前两幅更密集。 | 双重图像必须设计共享结构；“留白很多”不是全时期硬规则。要检查两种读法，而不只是有一个脸状物。 |
| [基金会：绘画时期概述](https://www.salvador-dali.org/en/dali-and-gala/dali-the-total-artist/painting/) | 官方资料说明古典绘画影响与后来核神秘主义方向；不把整个创作生涯混成一种手法。 | 第一版限于 1930 年代幻觉式油画。晚期、版画等要求重新读指定范围的原作；本轮未实测。 |

媒介、色彩和空间描述来自对公开数字复制品的观察与归纳；不据此主张原作颜料配方、精确色值或物理表面参数。英文海报字体属于本技能的成品适配，不能称为达利本人的固定排版语言。

## 元方法如何从上一轮经验迁移

- 保留观察→具体机制→实际提示→成图检查→归因修正的链路。
- 保留媒介、空间、材料、光色、字形与文字构图的相互检查，以及源图/风格参考/失败图的角色区别。
- 重新研究达利的绘画、变形、空间和观看方式；不继承韦斯的主体对称、人物看镜头、浅层摄影空间和柔暖胶片默认。
- 用户的已确认偏好与艺术家事实分层；案例中失败的名词不进入正常提示的长期禁词表。

## 真实试图

工具：当前环境内置 `image_gen`；两次文字生成与两次局部目标明确的编辑。未采用 CLI，也未验证其他宿主、图像模型或照片身份保持。生成提示与编辑提示逐字保存，编辑输入均为对应初稿，未使用原作风格图片。

### A：无法卸下的疲惫——柔软瓷杯

- [初始实际提示](../../skills/dali-surrealism/outputs/soft-porcelain/poster-v1.prompt.txt)
- [初始成图](../../skills/dali-surrealism/outputs/soft-porcelain/poster-v1.png)
- [编辑实际提示](../../skills/dali-surrealism/outputs/soft-porcelain/poster-v2.prompt.txt)
- [修正版成图](../../skills/dali-surrealism/outputs/soft-porcelain/poster-v2.png)

初稿中杯口、把手、下垂壁厚和受力支撑可读，巨大杯体与辽远海岸形成尺度差。但地面碎石、裂缝和亮面过于密集，整体偏精细 CG 的材质表现。

原因假设：提示强调精细材料，却没有明确细节应集中在哪里、环境如何概括。编辑保留几何与光线，将地面改为较大的连续色面，减少同等锐利的细节与亮点。

修正版保留了原先有效的变形与支撑，地面和岩石更接近绘画组织。核心材料转化、空间和可读性通过本轮目视检查；原作那种异常心理张力并不能凭一幅示例充分验证，审美仍待用户判断。

### B：房间记得住过的人——建筑与面孔

- [初始实际提示](../../skills/dali-surrealism/outputs/remembering-room/poster-v1.prompt.txt)
- [初始成图](../../skills/dali-surrealism/outputs/remembering-room/poster-v1.png)
- [编辑实际提示](../../skills/dali-surrealism/outputs/remembering-room/poster.prompt.txt)
- [修正版成图](../../skills/dali-surrealism/outputs/remembering-room/poster.png)

初稿同时出现房间与面孔，但鼻嘴成为墙上的解剖形浮雕。核心缺口是物体被直接画成了人体部件，不足以证明共享建筑轮廓的歧义。首次判为未完成；未将“有一张脸”算成通过。

原因假设：以“鼻梁/嘴唇”的命名指导物件映射，仍把模型拉向字面人体造型。编辑先明确平墙柱、破损边、石阶与接缝的几何，再说明它们的第二读法。

修正版消除了明显突出的鼻子，眼部仍由窗洞和窗帘组成；房间/面孔可以切换，建筑独立性改善。但面孔比例拉长、墙下沿仍有嘴形痕迹，精巧歧义仅部分达到预期。作为受限验证保留，不宣称复杂双重图像稳定通过。没有为此扩展成无限出图循环。

## 写回规则

两个公共技能都补充了“精细需要分配位置与层级”。达利技能进一步明确：双重图像的每个共享部位必须作为第一种物件独立成立，提示先写几何再说明第二读法。没有把杯子、房间、特定失败图、固定场景与私人路径放入公共技能。
