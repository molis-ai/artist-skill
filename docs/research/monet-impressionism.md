# 莫奈 Skill：研究与验证

日期：2026-09-11。只研究当前 Skill 需要的视觉决定；公开的数字复制品用于观察，不作为生成输入或打包图库。

## 本次实际出图

工具为当前内置 `image_gen`。先新文字生成，再对该生成图做一次局部绘画组织修正。实际提示逐字保存在 Skill 的 `outputs`；没有向模型传入莫奈原作，也未测试其他图像模型。

- 初稿：`pond-after-rain.png`；提示：`pond-after-rain.prompt.txt`。
- 修订：`pond-after-rain-refined.png`；编辑提示：`pond-after-rain-refined.prompt.txt`。
- 两张均为 1536 × 1024、无字画作。图片和提示归档到源码 Skill 的 `outputs`。

初稿：空椅、岸线、池塘与柳树关系成立；奶黄受光、蓝紫倒影及深绿植被互相呼应；横向水面笔触与下垂枝叶可区别。主要不足为椅子、花瓣和部分叶片描绘偏完整，带有工整插画感，不能仅因题材与用色吻合就宣布完全达到莫奈风格。

原因假设：提示写了松散笔触与可读景物，却没有落实到哪些小形体应合并、哪些边缘应省略。编辑保留构图和主色，明确合并部分浮叶与树叶色群，减弱逐瓣、逐条描绘，并保留必要识别短笔。

修订图保留了构图、光色、空椅与主要反射；椅子和植被的色块更概括，部分小笔触变大。睡莲花瓣仍偏整齐，整体短笔分布仍较密，边缘相融仅有有限改善。本次结论为：核心光色、水面和笔触方向可以执行，风格精确度部分达到预期；不称为原作级复刻。没有继续叠加模糊或表面滤镜。

因此只将可迁移的提示决定写回正文：指定哪些小形体合并为色群、哪些边缘相融、哪些短笔保留辨认。不把当前椅子和池塘布局变成通用模板，也不改其他艺术家 Skill。
