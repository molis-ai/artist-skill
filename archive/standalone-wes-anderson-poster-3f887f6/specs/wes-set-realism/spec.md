# 韦斯场景质感：从截图校准成像默认

## 背景与目标

用户先提供八组 prompt，再补充其对应的正面截图，认可“精心搭建的电影布景感”，要求按已讨论的视觉判断优化 Skill。截图中的场景具有清楚轮廓、柔和照明、饱满分区颜色、真实透视及材料光泽差异；教程标题、色卡与平台界面不作为场景本身的风格依据。截图不支持精确推断原图颗粒强度或色值。

当前 Skill 已补全道具、建筑、动作和色彩方法，但主文与实际提示仍反复默认浅空间、抬柔暗部、可见颗粒、哑光磨砂；这会压低结构反差、抹平材料光泽，并使需要真实纵深的场景过度扁平。

## 范围与方案

- 将共同视觉基础调整为经过精确美术设计的电影布景写实：明确机位、清楚结构、柔和受光、真实材料和连贯空间。
- 正面布局保留真实纵深；浅层压缩用于适合的构图，不给所有场景规定浅景深或相近远近尺度。
- 光照柔和而轮廓与暗部有分量；按材质保留布料、木、铜、石材和水的不同光泽。颗粒保持细微，哑光与抬黑按成品选择，不作为全部风格成立的硬条件。
- 饱满主色可占大面积，依靠颜色种类、区域、邻接和明暗建立协调；不自动降低全部彩度。
- 复古来自相容的建筑、家具、服装与器物造型，可以洁净完整；保留温暖环境中克制、疏离或专注的人物关系。
- 同步入口描述、材料/空间章节、实际提示与成图检查，消除旧默认冲突；条件参考仅修正相应空间表述。
- 保留默认 2:3 英文海报、所有字形/艺术排版规则、人物与物件比例、身份与用户覆盖权、色板数据及上一轮场景组织方法。不改其他三个 Skill，不自动生成图片。
