# 艺术风格 Skill：色彩方法与可执行色板

## 背景与目标

用户提供 https://github.com/karthik/wesanderson ，随后明确要求优化 Skill。本次将该仓库可核对的颜色组合转成可选择、可分配到画面、可进入实际提示的本地参考。原先色彩规范偏向柔暖灰土色，缺少具体色系入口，也容易将不同色系统一成米黄/棕色。

用户进一步要求把色彩与色板方法加入元 Skill，并同步更新莫奈与达利。三者现有正文已有光色观察，但尚未完整连接色板来源、选色、载体与媒介、实际提示及成图检查。本次沿用已研究的时期与原作依据；莫奈和达利新增的是创作方法及配色方向，不冒称官方 HEX 或颜料配方。

来源核对：仓库 README 说明其用途为 R 配色、首批来自 Wes Anderson Palettes；`R/colors.R` 提供实际色值及离散/连续插值行为；`DESCRIPTION` 与 `LICENSE` 声明 MIT、2022 Karthik Ram。它是社区整理的电影色板，不是导演官方调色规范或 LUT。本次的场景建议、颜色角色及面积分配属于海报设计适配。

## 方案与范围

- 在 `skills/wes-anderson-poster/references/wes-palettes.md` 保存去除重复别名和连续渐变后的独立离散色板、准确 HEX、来源与许可，以及简短选色建议。无 R 运行依赖，不下载电影图像，不把网络作为 Skill 运行前提。
- 修订 Skill 的配色决定、色彩章节、相关影调表述、实际提示和结果检查：先选色系，再把颜色落实到具体材质与面积关系，最后做保留色相关系的胶片调色。色板顺序不等于主次或面积，不要求用完所有颜色，不把色值当作整幅照片的硬替换目标。
- 保留布局、人体/物件比例、复古美术、字体和用户覆盖权；允许按照片身份色或明确要求自定义。少量暖感不应覆盖原方案的青绿、蓝紫、粉色或冷暖区别。
- 用准确色值做一个会话内可选择的色板预览，帮助直接查看不同组合；它不进入 Skill 运行包，也不冒充成图验证。
- 元 Skill 加入可迁移的色彩方法：区分原作复制品取色、已发表色板与创作建议，确认时期和媒介，观察色相/明度/彩度/面积/邻接，连接颜色角色、媒介表现、提示与结果检查。
- 莫奈按时段、天气、场景选择工作色板，将大色群拆为相邻笔触、下层色、有色阴影和反射；晚期睡莲与同景系列保留各自逻辑。
- 达利按空间和形体选择工作色板，指定亮面/半明面/暗面、远近与焦点的关系；让连续色阶支持形态转化和双重读法。
- 更新四个独立包、合集及根 README 的运行文件说明，纳入新增文字参考和许可。历史输出与旧验收记录不改。本轮不调用 Grok 或其他图像服务，不重复生成上一题。

## 输入输出与边界

输入：用户指定公共仓库的色板数据、现有四个 Skill、既有原作研究及此前已确认的色彩偏好。输出：四个本地可独立使用的规则、韦斯色板参考、四个独立 ZIP 与合集、会话色板预览。源码维护位置为 `/Users/yijunwang/code/artist-skill`；工作区保留本次准备与验证资料；本机既有发现链接继续指向同一源码。仅韦斯需要新增文字参考；其他三个 Skill 在正文中闭合方法。

## 验收与验证

1. 色板名和 HEX 与下载的上游原始数据一致；重复别名与连续色阶的处理明确，版权归属及许可保留。
2. 对照 scoped diff，四个 Skill 的配色选择、载体/面积、色值含义、媒介表现、实际提示和检查一致；保留既有布局、比例、字体、时期、母题与用户覆盖规则。元方法不能把韦斯胶片调色泛化给画家。
3. 人工检查韦斯的秋日庭院、清凉海岸、粉紫旅馆和照片保色选择；莫奈的阴天/斜阳系列与晚期水面；达利的软化形体与双重图像。记录具体决定及规则依据，不把提示示例当作成图证据。
4. 四个 Skill 结构校验通过；本机 `.codex` / `.agents` 既有入口及韦斯 `.grok` 入口仍可读；新增相对参考可达。五个 ZIP 含完整运行文件及必要文字参考，解包内容与源码相同，排除作品与工作记录。
5. 预览中的色值和名称与参考一致；文件读取确认是有效 HTML 片段。未运行浏览器和图像生成的项目明确说明。

完成等级：Skill 的配色规则与本地参考可用；本轮不宣称新版色系的图像生成效果已验证。
