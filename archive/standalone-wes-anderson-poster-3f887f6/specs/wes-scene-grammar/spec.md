# 从八组参考 prompt 补全韦斯场景方法

## 背景、目标与依据

用户提供八段正面参考 prompt，希望总结其中可复用的方法并优化现有韦斯 Skill。输入包含行李寄存室、餐厅调度、六房间剖面、双色房间、五连拱座、多层大堂、空泳池与分区大厅；个别文字存在拼接残缺，只提取清楚表达的构造，不猜缺失原文。

当前 Skill 已有布局、比例、摄影材料、电影色板与艺术化标题。缺口是：默认主角偏人物或物件；多人默认对镜头；背景默认柔焦退后。这些默认会妨碍建筑主导、道具阵列、分区叙事及人物各自行动的场景。色板已有“什么颜色放在哪”，还需补上“重复结构与空间分区如何组织颜色”。

来源等级：本轮只分析用户提供的 prompt 文本，没有对应生成图；所得方法是对参考文本的创作归纳，不冒称已观察电影原作或验证出图质量。

## 保留、替换与不纳入范围

- 保留：默认 2:3 英文电影海报；原字体设计、主体内部比例与相互尺度、摄影材料、胶片再现、22 组色板、用户输入优先；人物肖像海报的对视默认。
- 补全：建筑/空间系统可成为主角；道具分类与重复变化；人物角色、动作、目光、所处层级；剖面结构与局部纵深；色彩分区；留空与克制异常形成幽默或情绪。
- 调整：将强制主角对视、背景退后/柔焦限定在相应肖像构图；叙事场景按动作和空间职责选择。与建筑外壳相同的秩序不意味着单元内部内容镜像。
- 不将示例中的 4:3、无字、无人、红伞、行李、旅馆、固定房间数量或 1960 年代设为全局必需。不照搬输入中的损坏文字。不改元 Skill、莫奈或达利，不进行图像生成。

## 方案与关键行为

1. 输入区识别“作为生成任务的完整 prompt”与“提供学习的正面 prompt 参考”；明确要求执行时保留其画幅、文字与场景约束，学习时只提炼相应机制。
2. 构想阶段选择本次视觉主角：人物/物件、道具系统或建筑空间；同一张图的层级由选择决定。
3. 场景较复杂、道具主导、需要剖面或并置叙事时读取单个条件参考 `references/scene-composition.md`。参考提供结构方法及适用判断，不复刻八个成品模板。
4. 主文同步修改人物与背景的条件默认、色彩组织入口、实际提示骨架和成图检查，保证参考规则真能进入执行。
5. 更新韦斯独立包、合集和 README 的必要文件说明；保持其他 Skill 文件和历史作品不变。
