# 韦斯 Skill：恢复风格优先级并精简

## 背景与问题证据

用户在《The Sunday Connection》和《Low Tide Club》两次真实出图后指出已经失去韦斯·安德森风格，授权优化或简化 Skill。当前正文 246 行，构想、正文、长英文模板和检查重复描述写实、材料、自然比例；最近两份实际提示又将这些说明大幅展开。

海豹旧图的主题、比例、颜色及文字基本成立，但主体接近常见动物摄影：海豹近景、闪亮海水、沙粒细节和红色艺术字，场面编排弱。该提示额外排除了家具、建筑、人物等一切场景关系，这不是用户的限制。教堂图保留中轴拱廊与叙事，但摄影材质和旅游海报式标题比更独特的场面选择更强。不能用元素齐全或画质好代替风格成立。

原因假设：规则将通用摄影正确性置于识别骨架之前，实际编排进一步放大这一偏差；可见的形式秩序、角色与环境关系和具体美术选择没有成为先决设计。仅缩短提示或增加复古道具都不足以修复。

首次新版试图后补充：海豹与伞/空椅的关系、实体黄蓝配色已经出现，但现代铝架椅、未经明确选择的年代造型和直接鲜亮的摄影色调仍接近度假广告。精简版需要保留原有复古美术方向，并要求实际提示明确整体电影色调；不把“场面编排＋色板”当作已充分说明摄影再现。

## 目标、范围与保留项

- 保留真实体积和材料差别、自然人/物/动物比例、用户内容与源图保真；保留英文双层文案、2:3 默认、艺术字形与艺术文字构图、已有 22 组色板及许可。
- 恢复场面编排、机位、实体配色、克制关系的优先级；真实摄影用于实现这个场面，不再作为首要风格定义。维持原片可有自然景物、实景纵深、浓色、硬日光等变化，不退回强制抬黑、雾化、浅空间或全材质哑光。
- 精简主文与场景参考，合并重复说明，删除冗长英文填空模板。普通主题用简短且已做出选择的提示，不把完整规范交给图像模型。
- 只修改韦斯 Skill 主文、场景参考、色板的选用建议、入口短描述、根 README 与本次需求/验收记录；更新韦斯独立包和合集。其他 Skill、22 组离散色值、许可、原输出不改。
- 用相同“海豹在沙滩”主题和英文文案进行一次新生成，比较场景与风格变化。旧图只做诊断，不作为新图参考输入；最多两次针对同一问题的修正，没有进展则停止并如实记录。
- 本轮不包含 GitHub 推送；输出继续存入 Git 忽略的 `outputs/`。

## 用户补充与最终选色边界

用户提供《The Camel in Town》《Field Notes》《The Pelican Circuit》作为之前生成效果较好的案例，随后明确：应从已有色板出发，结合大众对韦斯的认知选色，不从这几张推断固定个人偏好，也不以其配色决定推荐顺序。旧例仅作为整体执行效果的参照；它们不是导演原作，也不是某组色板的准确采样。

据此更新默认选色建议：先考虑代表作中传播稳定的标志性色彩联想，再映射到已有色板：GrandBudapest2 的粉紫/淡蓝、Moonrise1/2 的黄绿/卡其/赭色、Zissou1 的蓝/黄/红。用官方宣传、原片图像与公开色彩分析支持这些关联；此优先组是创作判断，不是实测观众排名。其余色板按题材继续使用，完整离散色值与许可不变。不能因一次海豹图失败就下调 Zissou1，也不能以海水自然呈蓝色代替经过设计的实体色域。本次测试仍用文字生成以检查 Skill 独立作用。

## 使用场景、输入输出与依赖

简短主题：先形成可见的形式与情境，再编排短提示；允许与主题有关的美术扩写，不将空背景或道具数量固定化。详细描述与照片：保留指定的人数、动作、身份、结构与限制，在允许范围内安排机位、间距、色域和摄影。海报与无字场景沿用各自成品默认。

调用链：当前反馈及已有成图/实际提示 → 原片图像与摄影师一手访谈校准 → 精简唯一源码 → 从新版独立编排同题提示 → 内置 image_gen 全新生成 → 视觉审查 → 本地归档与分发包。工具使用宿主已提供的能力，不切换模型或新增服务。

依据范围：以《月升王国》《小行星城》的实拍图像和 Robert Yeoman 访谈校准构图、颜色与摄影的关系，不冒充导演全部作品的统一公式；英文艺术标题属于本项目海报适配。具体来源与观察写在 validation.md，不将研究日志塞入运行 Skill。
