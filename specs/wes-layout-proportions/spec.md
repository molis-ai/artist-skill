# 韦斯 Skill：布局秩序与人、物、场景比例

## 目标与证据

用户提供两张北京秋日海报，指出第一张布局混乱、风格不足，第二张人物身高观感异常；随后明确比例检查应覆盖物件及人体，并授权优化 Skill、使用 Grok 真实出图。

现有规则细写单体对称、画幅占比、胶片质感与字体，对全图共同秩序、对象内部比例及相互尺度缺少同等明确的决策；检查末尾仅有“比例符合要求”。第一张是拍屏，不能准确判断原始锐度和色彩。已在第二张原 Grok 会话找到并目视确认对应图片及实际提示：人物约占画幅三分之一，同时要求标题、银杏、院墙等区域。该布局压力是可能原因，不是已证实的唯一生成失败原因。

## 范围与完成等级

修改 `skills/wes-anderson-poster/SKILL.md` 的构想、主体编排、空间比例、实际提示骨架和成图检查。保留现有颜色、胶片、英文及字体方向、用户覆盖权、自然身高差异和单体结构对称边界。其他艺术 Skill 与元 Skill 不改；不把北京、栗子、自行车、固定头身比或固定布局写成通用默认。

更新韦斯独立 ZIP 与合集 ZIP；两处本机发现入口已链接源码，无需复制维护。用 Grok 的真实图像工具按修订 Skill 新生成一个同主题案例，归档实际提示、图片和评审。完成等级为规则可用并有一次 Grok 视觉实测，未测能力不扩称通过。

## 行为与方案

1. 先构建整幅的主轴、主要形状、对齐、间距、留白和遮挡秩序；人物、道具、建筑与标题组的总体重量共同服务构图。保留有意的差异与偏移，允许多人、多物。
2. 区分对象内部结构、人和物的相互尺度、同一场景的透视与接触。全身预留完整人体空间；服装遮挡下仍有可信关节位置。画幅占比与真实尺度联合确定，排不下时调整取景/对象位置/文字留白，不压短身体或机械拉扯物件。
3. 将本次具体编排、对象比例和尺度参照写入实际生成提示；成图先查布局和比例，再查材质配色文字。
4. 图像试验保留“北京秋天、成年女性全身、院门、自行车、手持栗子”的尺度参照，使用同题新构图。默认英文 High Autumn / The Air Was Finally Light。失败图仅用于诊断，不作为正面风格输入，也不要求复刻其人物身份。Grok 首次只生成一张；确有可定位缺陷时最多两次定向修正。

## 输入输出与调用链

用户两图与已确认反馈 → 定向修改 Skill → 主 Session 检查 scoped diff → 主 Session 根据修订 Skill 编排本次具体图像提示 → 只将图像提示提供给本机 Grok CLI → Grok image_gen → 主 Session 查看图像及实际工具提示 → 必要定向修正 → 保存 `outputs/beijing-autumn-layout/`、更新索引与发行包。

Grok 只获准使用图像生成/必要编辑工具，不修改仓库或配置、不调用下级 Agent、不用其他图像服务代替。沿用本机既有身份认证与默认模型；不读取或输出凭据。
